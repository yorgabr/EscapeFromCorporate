# Contributing to Escape From Corporate

Welcome. This guide is written for contributors new to PowerShell module development — take it step by step; you don't need prior Invoke-Build or Pester experience.

## Prerequisites

You'll need Windows 10 or 11 with **Windows PowerShell 5.1** (not just PowerShell 7) and Git. No administrator rights are required anywhere in this workflow — everything installs in user scope.

## First-Time Setup

```powershell
git clone https://github.com/yorgabr/escape-from-corporate.git
cd escape-from-corporate

# Bootstrap dev dependencies locally (Pester, PSScriptAnalyzer, Invoke-Build, platyPS).
# This downloads into .\modules\ only — nothing global, no admin.
.\tools\Install-BuildDependencies.ps1
```

## The Development Loop

We use `Invoke-Build`. Every task is defined in `efc.build.ps1`, at the project root, so Invoke-Build discovers it automatically — no `-File` argument needed.

```powershell
Import-Module InvokeBuild

Invoke-Build Lint     # static analysis
Invoke-Build Test     # runs Lint, then Pester
Invoke-Build .        # full pipeline
```

**Rule of thumb:** if `Test` passes locally, CI will pass too. The GitHub Actions workflow calls the exact same tasks.

## Project Layout (Where Things Live)

| Folder | What goes here |
|--------|----------------|
| `src/EscapeFromCorporate/Public/` | User-facing cmdlets (exported). One function per file. |
| `src/EscapeFromCorporate/Private/` | Internal engine. Grouped by domain: `Engine`, `Log`, `State`, `UI`, `Validation`. |
| `tests/Unit/` | Fast, isolated tests. Mock everything external. |
| `tests/Integration/` | End-to-end orchestration tests (still fully mocked — no real copies). |
| `tools/` | The dependency bootstrapper (`Install-BuildDependencies.ps1`). |
| `docs/` | Architecture reference and the usage guide. |

`efc.build.ps1` itself — the Invoke-Build pipeline definition — lives at the project root, not in a `build/` subfolder.

## Coding Standards

- **Language:** 100% English — code, comments, variables, docstrings, log messages.
- **One function per file**, named exactly as the file (e.g. `Get-EfcState.ps1`).
- **Comment-Based Help (CBH)** is mandatory on every **public** function: include
  `.SYNOPSIS`, `.DESCRIPTION`, `.PARAMETER`, and at least one `.EXAMPLE`.
- **`Set-StrictMode -Version Latest`** at the top of every function body.
- **No emojis** anywhere in the codebase.
- **Approved verbs only** (`Get-Verb`). Use `Invoke`, `Get`, `Write`, `Read`, etc.

One rule worth calling out on its own: under `Set-StrictMode -Version Latest`, reading a `$script:` variable that was never assigned throws — even inside `if (-not $var)`. If a function needs a lazily-initialized script-scoped cache (a compiled regex, a P/Invoke registration flag, a spinner frame index), declare and assign it eagerly at the top of the file, outside any function body, so the lazy-init check itself never touches an unset variable.

## Writing Tests

We use **Pester 5** syntax (not the legacy 3.x style).

```powershell
Describe 'Get-EfcSignature' {
    BeforeAll {
        Import-Module .\src\EscapeFromCorporate\EscapeFromCorporate.psd1 -Force
    }

    It 'normalizes equivalent paths to the same hash' {
        $a = Get-EfcSignature -Path 'C:\Data\'
        $b = Get-EfcSignature -Path 'c:\data'
        $a.Hash | Should -Be $b.Hash
    }
}
```

Key rules:
- Use `$TestDrive` for temporary files — Pester auto-cleans it.
- To test **private** functions, wrap assertions in `InModuleScope EscapeFromCorporate { }`. This isn't optional style: private functions aren't exported, so calling them directly from test scope fails with `CommandNotFoundException` the moment the module actually imports cleanly.
- **Never** execute a real `robocopy` transfer. Inject a fake via the `-ProcessFactory`
  or `-RobocopyRunner` parameters, or `Mock` the wrapper function.

### Testing the pause/resume engine

`Suspend-EfcProcess` calls the real `Get-Process -Id`, so when testing `Watch-RobocopyProcess` you MUST `Mock Suspend-EfcProcess` — never rely on a fake process object exposing a `.Handle`. To test `Suspend-EfcProcess` itself, spawn a real short-lived process (`Start-Process cmd.exe`) and always clean it up in a `finally` block. The function is contractually fail-safe: it returns `[bool]` and never throws, so assert on the return type when an EDR might block ntdll.

## Commit Messages (Conventional Commits)

The `Changelog` task parses these automatically. Format:

```
<type>(<optional scope>): <description>
```

Allowed types: `feat`, `fix`, `perf`, `refactor`, `docs`, `test`, `build`, `ci`, `chore`.

Examples:

```
feat(engine): add restartable mode flag
fix(log): correct byte offset drift on multibyte paths
docs(readme): document DryRun usage
```

Add a `!` after the type for breaking changes: `feat(cli)!: rename Source parameter`.

## Pull Request Checklist

- [ ] `Invoke-Build Test` passes locally.
- [ ] New/changed public functions have complete CBH with examples.
- [ ] Tests added for new behavior. Pester reports coverage against its default 75% target (see `artifacts\coverage.xml`); the build doesn't hard-fail below it, but a drop is worth a second look.
- [ ] Commit messages follow Conventional Commits.
- [ ] No global installs, no admin requirements introduced.

## Questions

Open an issue with the `question` label. Welcome aboard.

## 1. Design Goals & Constraints

The entire architecture is shaped by a hostile execution environment: a locked-down
corporate Windows 11 laptop with **no administrator rights**, **no third-party sync
tools** (Rsync/Rclone blocked), and **no global module installation**.

| Goal | Architectural consequence |
|------|---------------------------|
| Move tens of GB / hundreds of thousands of files reliably | Delegate the actual copy to `robocopy.exe` (battle-tested, native) |
| Never block the UI while copying | Background process + non-blocking async log polling |
| Survive interruption and resume exactly | JSON state persistence with the Log Pointer Offset strategy |
| Prove the copy is exact before deletion | Post-copy differential validation gate |
| Run with zero admin | User-space only; ntdll suspend for own processes; no services |
| Be maintainable and testable | Public/Private split; injectable process/runner seams; full mocking |

The core insight: **`efc` is a control plane, not a copy engine.** Robocopy does the
data movement; `efc` orchestrates, observes, persists, and validates around it.

## 4. The Watch Loop (Sequence)

The watch loop is the heart of the system. It runs on the **main PowerShell thread**
while robocopy runs as a **separate OS process**. There is no PowerShell runspace or
job involved - concurrency is achieved by delegating the heavy lifting to the OS
process and polling its side effects (the log file) cooperatively.

```mermaid
sequenceDiagram
    autonumber
    participant U as User (keyboard)
    participant W as Watch-RobocopyProcess (main thread)
    participant R as Read-RobocopyLog
    participant FS as FileStream (ReadWrite share)
    participant RC as robocopy.exe (OS process)
    participant ST as Write-EfcState
    participant UI as Write-EfcSpinner

    Note over RC,FS: robocopy writes to LOG file continuously
    loop every ~200ms until process exits AND log drained
        W->>R: Read delta from logByteOffset
        R->>FS: Open(Read, FileShare.ReadWrite) + Seek(offset)
        FS-->>R: only new bytes (currentLength - offset)
        R-->>W: Entries[], NewByteOffset, PartialLineBuffer
        W->>W: Add-EfcMetricsFromEntries (files, bytes, ETA, rate)
        W->>UI: render one frame (spinner, %, ETA, throughput)
        W->>U: Read-EfcKeyCommand (KeyAvailable? non-blocking)
        alt key == P / R / A
            W->>W: apply control intent (see section 8)
        end
        alt checkpoint interval elapsed
            W->>ST: atomic write state.json (temp + Replace)
        end
        W->>W: Start-Sleep 200ms (cooperative yield)
    end
    Note over W,RC: process exited -> deterministic drain loop
    loop until offset stabilizes (guard 200 iters)
        W->>R: drain read
        R-->>W: trailing Entries (late /LOG flush)
        W->>W: Add-EfcMetricsFromEntries
    end
    W->>ST: final atomic write (exitCode, status)
```

### Why this is non-blocking

- **No `WaitForExit()`** on the main thread. The loop checks `HasExited` per
  iteration and keeps rendering/reading.
- **No STDOUT pipe.** Robocopy writes to its own `/LOG` file; there is no pipe buffer
  to drain, so no deadlock is possible even on massive transfers.
- **No blocking read.** `Read-RobocopyLog` reads only `currentLength - offset` bytes
  and returns immediately; it never waits for more data.
- **No blocking key read.** `Read-EfcKeyCommand` calls `[Console]::KeyAvailable`
  first and only consumes a key when one is queued.

The `Start-Sleep 200ms` is the sole intentional yield: it keeps CPU near-idle while
preserving a responsive UI cadence (5 frames/second).

## 5. Log Pointer Offset Mechanics

This is the strategy that makes exact resumption possible. The persisted
`logPointer.logByteOffset` is the **byte position up to which the log has been fully
consumed and reconciled into metrics.**

### The partial-line problem

Robocopy may flush a buffer mid-line. A naive `ReadLine` loop would either block
waiting for the newline or mis-parse a truncated line. The solution splits every
delta into *complete lines* (fully terminated) and a *residual partial line* carried
forward.

```
Poll N reads delta bytes:  "...file9.txt\nNew File \t1024\tC:\data\file1"
                            |------ complete ------|--- partial (no \n yet) ---|
                                                    ^
                            PartialLineBuffer <-----+  (carried to poll N+1)

Poll N+1 delta:            "0.bin\nNew File \t2048\tC:\data\file11.txt\n"
Working buffer:            "New File \t1024\tC:\data\file10.bin\n..."
                            (partial prepended)  ^ now complete -> parsed
```

### Byte-accuracy with multibyte UTF-8

The offset advances by **bytes**, but PowerShell string operations work in
**characters**. For a path like `arquivo-ção.txt`, character count != byte count.
The authoritative formula measures the residual partial in bytes explicitly:

```
newPartialBytes = Encoding.UTF8.GetByteCount(newPartial)
NewByteOffset   = ByteOffset + (bytesReadThisPass - newPartialBytes)
```

The prior `PartialLineBuffer` came from bytes **already counted** in `ByteOffset`, so
it is not double-counted: we only add `(read - newPartialBytes)`, where `read` is the
delta of *this* pass.

### Resume integrity

On resume, `Test-EfcResumePointer` verifies the byte immediately before the offset is
a newline (`0x0A`), or the offset is `0` / exactly EOF. If the log was truncated or
rotated (offset past EOF, or mid-line), the pointer is rejected and the caller falls
back to a `DifferentialRestart` (offset reset to 0), trusting robocopy to skip
already-copied identical files.

```mermaid
flowchart TD
    A[Resume requested] --> B{offset == 0?}
    B -- yes --> OK[Valid: start of file]
    B -- no --> C{log file exists?}
    C -- no --> BAD[Invalid -> DifferentialRestart]
    C -- yes --> D{offset > file length?}
    D -- yes --> BAD
    D -- no --> E{offset == file length?}
    E -- yes --> OK
    E -- no --> F{byte at offset-1 == 0x0A?}
    F -- yes --> OK
    F -- no --> BAD
```

## 6. State Lifecycle

The `state.json` file at `%LOCALAPPDATA%\EscapeFromCorporate\state.json` is the single
persistent artifact. Its `status` field is the primary state machine.

```mermaid
stateDiagram-v2
    [*] --> Created: New-EfcState
    Created --> Running: process spawned
    Running --> Paused: [P] pressed
    Paused --> Running: [R] pressed
    Running --> Aborted: [A] pressed
    Running --> Completed: exit<8 AND mismatches==0
    Running --> ValidationFailed: exit<8 AND mismatches>0
    Running --> Failed: exit>=8
    Aborted --> Running: re-run / Resume-EfcJob
    Failed --> Running: re-run / Resume-EfcJob
    ValidationFailed --> Running: re-run (differential)
    Completed --> [*]
    Aborted --> [*]: Clear-EfcState
```

### Atomic persistence

`Write-EfcState` never writes `state.json` in place. It writes `state.json.tmp`, then:

- If a prior file exists: `[System.IO.File]::Replace(tmp, primary, backup)` -
  atomic on NTFS, with a `.bak` sidecar for crash recovery.
- Otherwise: `[System.IO.File]::Move(tmp, primary)`.

`Get-EfcState` mirrors this: if `state.json` is missing but `state.json.tmp` exists
(a crash mid-rename), it salvages the temp file. Corrupt/partial JSON returns `$null`
(treated as a fresh start) rather than throwing.

### Checkpoint throttling

The watch loop persists at most once per `resumption.checkpointIntervalSeconds`
(default 15s), not every iteration. This bounds disk I/O to ~4 writes/minute even at
5 frames/second, while keeping the resume granularity acceptable (worst case: replay
~15s of already-copied files, which robocopy skips as identical).

## 7. Resumption Decision Flow

`Resolve-EfcResumption` is a **pure function**: given the existing state and the
request, it returns a decision without side effects. `Invoke-EfcJob` applies it. This
separation keeps the decision matrix fully unit-testable in isolation.

```mermaid
flowchart TD
    START([Invoke-EfcJob]) --> FORCE{-Force set?}
    FORCE -- yes --> FR[ForceRestart<br/>discard prior state]
    FORCE -- no --> EXIST{prior state exists?}
    EXIST -- no --> FS[FreshStart]
    EXIST -- yes --> KEY{combinedKey matches?}
    KEY -- no --> CONF[Conflict<br/>throw, require -Force]
    KEY -- yes --> DONE{status == Completed?}
    DONE -- yes --> AC[AlreadyCompleted<br/>return, no work]
    DONE -- no --> PTR{resume pointer valid?}
    PTR -- yes --> RES[Resume<br/>continue at offset]
    PTR -- no --> DR[DifferentialRestart<br/>offset=0, robocopy skips identical]

    FR --> BUILD[New-EfcState]
    FS --> BUILD
    DR --> BUILD
    RES --> REHYDRATE[rehydrate existing state]
    BUILD --> SPAWN
    REHYDRATE --> SPAWN([Connect-Robocopy])
    CONF --> STOP([throw])
    AC --> STOP2([return])
```

The `combinedKey` is `SHA1(normalizedSource)[0..8] + '-' + SHA1(normalizedDest)[0..8]`.
Path normalization (lowercase, trimmed trailing separators) means `C:\Data\` and
`c:\data` produce the same key - the job identity is robust to cosmetic path
differences.

## 8. Pause / Resume / Abort Control

Robocopy has **no native pause**. `efc` implements true suspension via
`NtSuspendProcess` / `NtResumeProcess` from `ntdll.dll` (callable without admin for
processes the current user owns), with a soft-pause fallback.

```mermaid
sequenceDiagram
    autonumber
    participant U as User
    participant W as Watch loop
    participant S as Suspend-EfcProcess
    participant RC as robocopy.exe

    U->>W: press [P]
    W->>S: Suspend(PID)
    alt native suspend succeeds (NTSTATUS 0)
        S->>RC: NtSuspendProcess(handle)
        RC-->>S: threads frozen
        S-->>W: $true (hard pause)
        W->>W: isPaused=true, status=Paused, stop reading delta
    else P/Invoke blocked (EDR) or fails
        S-->>W: $false (soft pause)
        W->>W: isPaused=true, stop reading delta (robocopy keeps running)
    end

    U->>W: press [R]
    W->>S: Resume(PID)
    S->>RC: NtResumeProcess(handle)
    W->>W: isPaused=false, resumeCount++, status=Running
    Note over W,RC: on resume, Read-RobocopyLog catches up<br/>from persisted offset (progress may "jump")

    U->>W: press [A]
    W->>S: Resume(PID) if paused
    W->>RC: Stop-RobocopyProcess -> Kill + WaitForExit(5s)
    W->>W: status=Aborted, break loop
```

### Hard pause vs soft pause

- **Hard pause** (native suspend succeeded): robocopy threads are frozen; no CPU, no
  disk, no network. The transfer is truly halted.
- **Soft pause** (fallback): robocopy keeps running in the background, but `efc` stops
  consuming the log delta. On resume, the reader catches up from the persisted offset.
  No data is lost; the only visible effect is a progress "jump."

`Suspend-EfcProcess` is **contractually fail-safe**: it returns `[bool]` and never
throws, because pause is a best-effort UX feature that must never crash an in-flight
transfer. This matters in corporate environments where an EDR agent may block ntdll
P/Invoke.

## 9. Integrity Validation & the Safe-to-Delete Gate

The `safeToDeleteSource` flag is the most consequential field in the entire system -
it is the signal that authorizes the user to delete their source data. It defaults to
`false` and only flips to `true` under strict conditions.

Optional **sampled SHA256 hashing** is now exposed on the public surface via
`Invoke-EfcJob -SampleHashCount <n>` (0-10000), which flows through to
`Test-EfcCopyIntegrity`. The chosen count and the resulting
`hashSamplesChecked` / `hashMismatches` are persisted under `state.json`
`validation.*` for audit traceability.

```mermaid
flowchart TD
    EXIT[robocopy exits] --> CODE{exitCode < 8?}
    CODE -- no --> FAIL[status=Failed<br/>safeToDelete=false]
    CODE -- yes --> VAL[Test-EfcCopyIntegrity]
    VAL --> LIST[robocopy /L second pass]
    LIST --> COUNT{files still listed?}
    COUNT -- yes --> VF[status=ValidationFailed<br/>safeToDelete=false]
    COUNT -- no --> HASH{sampled hashing enabled?}
    HASH -- no --> PASS[mismatchCount=0<br/>safeToDelete=TRUE]
    HASH -- yes --> SAMPLE[SHA256 sample subset]
    SAMPLE --> HM{any hash mismatch?}
    HM -- yes --> VF
    HM -- no --> PASS
```

### The differential validation principle

After a successful copy, a second `robocopy /L` (list-only) pass over the same
source/destination pair should report **zero** pending files - because every source
file must now exist identically at the destination. Any file robocopy still lists as
needing to copy is, by definition, a mismatch.

Robocopy's own comparison (size + timestamp) is the primary gate. Optional
**sampled SHA256 hashing** (`-SampleHashCount`) adds content-level assurance for
critical transfers without the prohibitive cost of hashing every file in a
tens-of-GB tree.

Robocopy exit codes are interpreted per the official semantics:

| Exit code | Meaning | efc treatment |
|-----------|---------|---------------|
| 0 | Nothing to copy (already in sync) | Success |
| 1-7 | Files copied / extras / mismatches handled | Success (proceed to validate) |
| >= 8 | Serious error (access, fatal) | `Failed`, no validation |

## 10. Failure Modes & Mitigations

| Failure mode | Mitigation |
|--------------|-----------|
| Process killed mid-write of `state.json` | Atomic temp+Replace; `.bak` recovery; `Get-EfcState` salvages `.tmp` |
| Robocopy flushes log AFTER `HasExited` | Deterministic drain loop until offset stabilizes (guard 200 iters) |
| Log truncated / rotated on resume | `Test-EfcResumePointer` rejects invalid offset -> `DifferentialRestart` |
| Multibyte path corrupts offset | Byte-accurate advance via `GetByteCount`, not char length |
| ntdll suspend blocked by EDR | `Suspend-EfcProcess` returns `$false` -> soft-pause fallback |
| STDOUT pipe deadlock on huge transfer | No pipe; robocopy writes to its own `/LOG` file |
| UNC destination unreachable | `Test-EfcPreflight` guards server reachability before spawn |
| Conflicting job in state slot | `Resolve-EfcResumption` returns `Conflict`; requires `-Force` |
| Non-interactive host (CI/ISE) | `Test-EfcInteractiveHost` -> degrade spinner to throttled linear output |
| EOL normalization corrupts test fixtures | `.gitattributes` marks `tests/**/*.log` as `-text` (binary) |
| Runaway drain on pathological log | Hard cap of 200 drain iterations (~5s worst case) |

## 11. Testability Seams

Every OS interaction is injectable, so the entire system is testable **without moving
a single byte of real data**.

| Seam | Parameter | What it replaces |
|------|-----------|------------------|
| Process spawn | `Connect-Robocopy -ProcessFactory` | Real `robocopy.exe` launch |
| List enumeration | `Test-EfcPreflight -RobocopyRunner` | `robocopy /L` for DryRun |
| Integrity list | `Test-EfcCopyIntegrity -RobocopyRunner` | `robocopy /L` validation pass |
| State location | `-StateRoot` (all state functions) | `%LOCALAPPDATA%` path |
| Log growth | Synthetic files in `$TestDrive` | Robocopy writing the log |
| Native suspend | `Mock Suspend-EfcProcess` | ntdll P/Invoke |
| Host interactivity | `Mock Test-EfcInteractiveHost` | Real console detection |

### Testing philosophy

- **Unit tests** (`tests/Unit/`) exercise one function with all external calls mocked.
- **Integration tests** (`tests/Integration/`) drive `Invoke-EfcJob` end-to-end with
  the process factory and runners faked, and a synthetic log materialized on disk.
- **No test ever executes a real robocopy transfer.** The largest artifact any test
  touches is a synthetic log of a few kilobytes.
- **Byte-offset assertions** rely on fixtures being preserved byte-for-byte, which is
  why `.gitattributes` freezes `tests/**/*.log`.

For the full mocking strategy and contributor workflow, see
[CONTRIBUTING.md](../CONTRIBUTING.md).

## 12. ADR-001: Robocopy Output Locale

**Status:** Accepted
**Context:** Robocopy localizes its per-file action labels ("New File" becomes
"Arquivo Novo" on pt-BR, "Neue Datei" on de-DE). The primary parser regex is
anchored on English labels for the rich `Action` classification.

**Decision:** The parser is intentionally English-label-first, with a
language-agnostic **sized-file fallback** (`^\s+\d+\s+<drivepath>$`) that recovers
the essential metrics (size + path) regardless of the OS display language. The
action label may be lost on localized systems, but file counts and byte totals -
the metrics that drive progress and the safe-to-delete gate - remain accurate.

**Consequences:**
- On a localized OS, `Action` may be reported as the generic 'Copy' rather than
  'New File'/'Newer'/etc. This does not affect correctness of metrics or validation.
- For maximum fidelity, users may run efc under an English-language robocopy by
  ensuring the process UI culture is en-US, though this is not required for correct
  operation.
- This behavior is locked by the fuzz suite (`ConvertFromRobocopyLine.Fuzz.Tests.ps1`)
  so any regex change that breaks the fallback is caught immediately.

    participant PF as Test-EfcPreflight
    participant RR as Resolve-EfcResumption
    participant CR as Connect-Robocopy
    participant WL as Watch-RobocopyProcess
    participant IV as Test-EfcCopyIntegrity
    participant WS as Write-EfcSummary

    User->>IJ: Invoke-EfcJob -Source -Destination
    IJ->>PF: validate + (DryRun projection)
    PF-->>IJ: IsValid, totals
    IJ->>RR: reconcile against state.json
    RR-->>IJ: decision (Resume/Fresh/Conflict/...)
    alt Conflict
        IJ-->>User: throw (require -Force)
    else proceed
        IJ->>CR: spawn robocopy (background, /LOG)
        CR-->>IJ: process, PID, commandLine
        IJ->>WL: watch (render + control + checkpoint)
        WL-->>IJ: final state (exitCode)
        alt exitCode < 8
            IJ->>IV: differential validation
            IV-->>IJ: mismatchCount
        end
        IJ->>WS: render summary + safe-to-delete signal
        WS-->>User: "SAFE TO DELETE" or failure notice
    end
```

# Invoke-EfcJob

## SYNOPSIS
Securely copies a directory tree to a destination (local or UNC) with resumable, validated, progress-tracked transfers powered by robocopy.

## SYNTAX

```
Invoke-EfcJob [-Source] <String> [-Destination] <String> [-Force] [-DryRun] [-Restartable]
 [[-SampleHashCount] <Int32>] [[-StateRoot] <String>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Invoke-EfcJob is the primary controller for Escape From Corporate. It orchestrates the full lifecycle of a secure file dump:

1. Pre-flight validation and (optionally) a DryRun projection of pending work.
2. Idempotent resumption reconciliation against any persisted state.json.
3. Background robocopy spawn with file-based logging (no pipe deadlock).
4. A non-blocking watch loop rendering a live spinner, ETA, percentage, and throughput, while capturing P/R/A keystrokes for Pause/Resume/Abort.
5. Atomic checkpoint persistence to allow interrupted jobs to resume exactly.
6. Post-copy integrity validation and a clear "safe to delete" signal.

The utility is designed for locked-down corporate Windows 11 environments with no administrator privileges and no third-party sync tools; it relies solely on native PowerShell 5.1 and robocopy.exe.

## EXAMPLES

```

### Example 4: Restartable mode over a flaky link (using the alias)

## 1. Before You Start

`efc` is built for a specific situation: a locked-down corporate Windows laptop with
no admin rights, moving large volumes of files to a home NAS over the local network.

You'll need Windows PowerShell 5.1 (built into Windows 10/11), network access to your
destination (a UNC share such as `\\HOME-NAS\Backup`), and enough free space at the
destination for the full source tree.

**Import the module:**

```powershell
Import-Module .\src\EscapeFromCorporate\EscapeFromCorporate.psd1
```

**Verify it loaded and read the help:**

```powershell
Get-Command -Module EscapeFromCorporate
Get-Help Invoke-EfcJob -Full
```

You can call the primary command as `Invoke-EfcJob`, or via the aliases `efc`,
`Invoke-Efc`, or `Escape-FromCorporate`.

---

## 2. The Golden Path (Typical Workflow)

The recommended end-to-end flow for a first-time transfer:

**Step 1 - Size it first (no data moved):**

```powershell
efc -Source 'C:\Users\me\CorporateData' -Destination '\\HOME-NAS\Backup\Dump' -DryRun
```

This prints the projected file count and total bytes so you can confirm the
destination has room and estimate how long it will take.

**Step 2 - Run the transfer:**

```powershell
efc -Source 'C:\Users\me\CorporateData' -Destination '\\HOME-NAS\Backup\Dump'
```

A live display appears: a spinner, percentage, throughput, file counters, and ETA.
The control hint reminds you of the runtime keys:

```
Transfer running. Controls: [P]ause  [R]esume  [A]bort
```

**Step 3 - Let it finish and read the verdict:**

When robocopy completes, `efc` runs a post-copy integrity check automatically and
prints a summary. If everything matched, you will see:

```
 VALIDATION PASSED - Source files are SAFE TO DELETE.
 Verify the destination before removing anything.
```

**Step 4 - Verify, then (optionally) reclaim space:**

Spot-check the destination yourself. Once satisfied, you may delete the source and
clean up efc's state and logs:

```powershell
Clear-EfcState -IncludeLogs
```

> **Important:** `efc` never deletes your source files. It only tells you when it is
> safe to do so. The deletion is always your explicit, manual action.

---

## 3. Scenario: Sizing a Transfer with DryRun

**Goal:** Know the workload before committing.

`-DryRun` runs a list-only enumeration (`robocopy /L`) - it reads the source but
copies nothing.

```powershell
efc -Source 'C:\Data' -Destination '\\NAS\Dump' -DryRun
```

Sample output:

```
DryRun projection (no data copied):
  Files : 284,531
  Bytes : 32,212,254,720 (30.00 GB)
  Dirs  : 1,204
```

Use it to confirm the destination has enough free space, estimate duration by
dividing total bytes by your typical LAN throughput, and sanity-check that you
pointed at the right source folder before committing to a long run.

DryRun is safe to run repeatedly and never touches state.json.

---

## 4. Scenario: Recovering from a Network Drop

**The situation:** You are 60% through a 30 GB transfer to the NAS and the Wi-Fi
drops, or you close the laptop lid, or PowerShell is killed.

**What efc did automatically:** Throughout the run, efc checkpointed its progress to
`state.json` every 15 seconds, recording the exact byte offset in the robocopy log
up to which files were counted.

**How to recover - just run the same command again:**

```powershell
efc -Source 'C:\Data' -Destination '\\NAS\Dump'
```

efc detects the matching interrupted job and resumes:

```
Resuming interrupted job (offset 21943040).
```

**Or use the explicit resume command** (reads source/destination from the saved
state, so you do not have to retype them):

```powershell
Resume-EfcJob
```

**Why this is safe and fast:** robocopy is a differential engine. On resume, it skips
every file that already exists identically at the destination (same size and
timestamp) and copies only what remains. You will see the progress bar advance
quickly at first as robocopy re-scans and skips completed files - this is expected,
not a glitch.

**If the log pointer was corrupted** (rare - e.g. the log file was truncated), efc
falls back to a differential restart and tells you:

```
Note: resuming via robocopy differential. Progress may jump as identical files are skipped.
```

The outcome is identical; only the internal bookkeeping differs.

---

## 5. Scenario: Pausing to Free Bandwidth

**The situation:** A large transfer is saturating your home network and you need
bandwidth for a video call.

**Press `P`** at any time during the transfer. efc suspends the robocopy process:

```
Paused (process suspended). Press [R] to resume.
```

While paused, robocopy consumes no CPU, disk, or network - the transfer is truly
frozen, not just hidden.

**Press `R`** to resume when you are done:

```
Resumed.
```

> **Corporate EDR note:** Some corporate security agents block the low-level process
> suspension API. If that happens, efc automatically falls back to a "soft pause": it
> stops updating the display, but robocopy keeps running in the background. You will
> see `Paused (soft-pause)` instead. This is a graceful degradation - your transfer is
> never at risk, and resuming works the same way. When you resume, the progress may
> jump forward to catch up on what completed during the soft pause.

---

## 6. Scenario: Aborting Safely

**The situation:** You started the wrong transfer, or you simply need to stop.

**Press `A`.** efc stops the robocopy process cleanly and saves state:

```
Abort requested. Stopping transfer...

 Job aborted. State saved; re-run to resume.
```

Aborting is safe: the partial copy at the destination is intact, and the state is
preserved. You can resume later with the same command or `Resume-EfcJob`, or discard
everything and start fresh with `-Force`.

Aborting does **not** delete anything - not the source, not the partial destination.

---

## 7. Scenario: High-Assurance Validation with Sampled Hashing

**The situation:** The data is critical (legal, financial, medical) and size-plus-
timestamp matching is not enough assurance for you.

By default, efc validates using robocopy's differential list pass - a fast, reliable
check that every source file now exists identically at the destination. For deeper
assurance, request **content-level SHA256 verification of a random sample** of files
via `-SampleHashCount`:

```powershell
efc -Source 'C:\Legal\Case' -Destination '\\NAS\Vault' -SampleHashCount 200
```

**What sampled hashing does:** After the copy, efc picks the requested number of random
source files, computes their SHA256 hashes, and compares them byte-for-byte against the
corresponding destination files. Any mismatch (or missing destination file) fails
validation and blocks the safe-to-delete signal.

**Why sample instead of hashing everything:** Hashing every file in a tens-of-GB tree
would take as long as the copy itself. Sampling gives strong statistical confidence at
a fraction of the cost. Choose a sample size proportional to your risk tolerance -
larger samples for more critical data (the maximum is 10,000 files per run).

**Interpreting the result:** The summary reports the method
(`RobocopyList+SampledSHA256`) and the combined mismatch count. The final state records
`validation.sampleHashCount`, `validation.hashSamplesChecked`, and
`validation.hashMismatches` for audit purposes. Zero mismatches from both the list pass
and the hash sample is the only condition that flips `safeToDeleteSource` to true.

**Inspecting the audit trail afterward:**

```powershell
Get-EfcJobState | Select-Object -ExpandProperty validation
```
---

## 8. Scenario: Starting Over with -Force

**The situation:** You want to discard a previous job entirely and start clean - for
example, the previous destination was wrong, or the state is confusing you.

```powershell
efc -Source 'C:\Data' -Destination '\\NAS\Dump' -Force
```

`-Force` discards any existing state for this source/destination pair and begins a
fresh transfer. It does **not** delete files already at the destination; robocopy will
simply re-evaluate them and skip identical ones.

**When you will be told to use -Force:** If you try to run a job whose source or
destination differs from the one already saved in state, efc refuses and protects the
existing job:

```
Existing state targets a different source/destination pair
(key 'a94a8fe5-0beec7b5' vs '1d7c5b8a-3e46f8a1'). Use -Force to override.
```

This guard prevents you from accidentally clobbering an in-progress job by pointing at
a different folder. If you genuinely want to switch jobs, add `-Force` (or clear the
old state first with `Clear-EfcState`).

---

## 9. Understanding the Safe-to-Delete Gate

This is the most important concept in efc. The `safeToDeleteSource` signal is the only
thing that authorizes you to delete your source data, and it defaults to **false**.

It flips to **true** only when **all** of the following hold:

1. Robocopy exited with a success code (below 8).
2. The post-copy differential list pass reports **zero** pending files.
3. If sampled hashing was requested, **zero** hash mismatches.

If any check fails, you will see one of:

```
 VALIDATION FAILED - 3 mismatch(es). Do NOT delete the source.
```

or

```
 Escape From Corporate - Job Failed
 ...
```

**Rule of thumb:** If you did not see the green "SAFE TO DELETE" message, treat the
source as not yet safely copied. Re-run the command to let robocopy complete the
remaining or mismatched files, then let validation run again.

Even when efc says it is safe, **spot-check the destination yourself** before deleting.
efc is a careful assistant, not a substitute for your judgment on irreplaceable data.

---

## 10. Reading the Live Progress Display

During a transfer you will see a single status line updating in place:

```
/  30.0% | 9.00 GB/30.00 GB | 40.00 MB/s | files 84,210/284,531 | ETA 00:08:57
```

| Segment | Meaning |
|---------|---------|
| `/` | Spinner frame - confirms efc is actively polling (rotates: `| / - \`) |
| `30.0%` | Percentage of total bytes copied |
| `9.00 GB/30.00 GB` | Bytes copied / total bytes expected |
| `40.00 MB/s` | Current average throughput |
| `files 84,210/284,531` | Files copied / total files expected |
| `ETA 00:08:57` | Estimated time remaining (hh:mm:ss) |

When paused, the spinner is replaced by `[||]`.

**On non-interactive hosts** (CI, redirected output, the ISE), the in-place display
degrades gracefully to a periodic linear line printed every few seconds, so logs
remain readable without cursor tricks.

---

## 11. Robocopy Exit Codes

efc interprets robocopy's exit code to decide whether to validate. Robocopy uses a
bitmask where higher values indicate more serious conditions:

| Exit code | Meaning | efc treatment |
|-----------|---------|---------------|
| 0 | No files copied; source and destination already in sync | Success |
| 1 | Files copied successfully | Success |
| 2 | Extra files/dirs detected at destination | Success |
| 3 | Files copied + extras present | Success |
| 5, 6, 7 | Combinations of copied/mismatched/extra | Success (validated) |
| **8 and above** | At least one failure (access denied, path error, etc.) | Failed - no validation |

Any code **below 8** is treated as a successful robocopy run, after which efc proceeds
to integrity validation. Codes **8 or higher** mark the job as `Failed`, and the
safe-to-delete gate stays closed.

The exact exit code is shown in the final summary and stored in `state.json` under
`robocopy.exitCode` for diagnostics.

## 12. Troubleshooting

### "Pre-flight validation failed"

**Cause:** The source does not exist, is not a directory, or the destination server is
unreachable.

**Fix:**
- Confirm the source path exists: `Test-Path 'C:\Data'`.
- Confirm the NAS is online and the share is reachable: `Test-Path '\\HOME-NAS\Backup'`.
- If on VPN, ensure the tunnel is up before running efc.

### "Use -Force to override" (Conflict)

**Cause:** A saved job targets a different source/destination than the one you just
specified.

**Fix:** Either resume the original job by matching its paths, or intentionally switch
by adding `-Force`, or clear the old job with `Clear-EfcState`.

### Progress "jumps" forward on resume

**Cause:** This is expected. On resume, robocopy re-scans and skips files that already
exist identically, so the counter races ahead until it reaches the point of
interruption.

**Fix:** None needed - this is correct differential behavior.

### Pause shows "soft-pause" instead of "process suspended"

**Cause:** A corporate security agent (EDR) blocked the low-level suspension API.

**Fix:** None required. The transfer continues correctly in the background; resume
works normally. If you must hard-pause, the only workaround is environment-dependent
and typically outside your control on a locked-down machine.

### The transfer is slow

**Causes and levers:**
- **Network is the bottleneck.** LAN throughput caps your speed; efc adds negligible
  overhead. Check your NAS and switch link speeds.
- **Many tiny files.** Hundreds of thousands of small files are inherently slower than
  a few large ones due to per-file overhead. This is a robocopy/filesystem reality.
- **Restartable mode (`/Z`) adds overhead.** If you enabled `-Restartable` on a stable
  link, consider dropping it - it trades speed for resilience.

### Validation failed after what looked like a complete copy

**Cause:** Some files could not be copied (locked, permission-denied) or changed during
the copy.

**Fix:** Re-run the same command. Robocopy retries and copies the outstanding files;
validation runs again. Check `state.json` `metrics.filesFailed` and the robocopy log
under the state's `logs` folder for the specific paths.

### I lost track of a running job

**Fix:** Inspect the saved state at any time:

```powershell
Get-EfcJobState | Select-Object status, @{n='pct';e={$_.metrics.percentComplete}}
```

## 13. Frequently Asked Questions

**Does efc ever delete my source files?**
No. efc only signals when a copy is validated and safe to delete. Deletion is always
your manual action.

**Where is the state stored?**
In `%LOCALAPPDATA%\EscapeFromCorporate\state.json`, with robocopy logs under the `logs`
subfolder. Override with `-StateRoot` if needed.

**Can I run two different transfers at once?**
efc tracks a single active job in its default state slot. To run genuinely independent
jobs, give each a separate `-StateRoot` directory.

**Does it work to a local drive, not just a NAS?**
Yes. Any destination robocopy accepts works - local drives, external USB, and UNC
shares alike.

**Do I need administrator rights?**
No. efc runs entirely in user space. The only privileged-looking operation - process
suspension for pause - uses an API available for your own processes without elevation,
and degrades gracefully if blocked.

**Can I resume on a different day?**
Yes. State persists on disk. As long as the source and destination paths are the same,
running the command (or `Resume-EfcJob`) picks up where you left off.

**What if the destination already has some of the files?**
robocopy skips identical files and copies only what differs or is missing. This is why
`-Force` is safe: it re-evaluates the destination rather than blindly recopying.

**How accurate is the ETA?**
The ETA is a running estimate based on average throughput so far. It stabilizes as the
transfer progresses and can swing early on or when file sizes vary widely.

# ------------------------------------------------------------------------------
# Path anchoring
# ------------------------------------------------------------------------------
# efc.build.ps1 lives at the project root in this repository layout, so
# ProjectRoot IS BuildRoot - there is no "build\" subfolder to climb out of.
# (Do NOT use Split-Path -Parent here; that was a leftover assumption from a
# layout where this script lived one level down, e.g. .\build\efc.build.ps1,
# and it silently resolves one directory too high, breaking every path below.)

# ==============================================================================
# TASK: Lint
# Static analysis via PSScriptAnalyzer. Depends on Bootstrap.
# ==============================================================================
task Lint Bootstrap, {
    Import-Module PSScriptAnalyzer -MinimumVersion '1.21.0' -Force

    $settingsPath = Join-Path $TestsRoot 'PSScriptAnalyzerSettings.psd1'

    if (-not (Test-Path -LiteralPath $SourceRoot)) {
        throw "Source root not found: $SourceRoot. Check `$ProjectRoot/`$SourceRoot path anchoring in efc.build.ps1."
    }
    if (-not (Test-Path -LiteralPath $settingsPath)) {
        throw "PSScriptAnalyzer settings not found: $settingsPath."
    }

    Write-Build Cyan "Analyzing source with settings: $settingsPath"

    # NOTE: deliberately NOT calling `Invoke-ScriptAnalyzer -Path $SourceRoot
    # -Recurse` in one shot. The PSUseCompatibleSyntax rule (enabled in
    # PSScriptAnalyzerSettings.psd1) keeps mutable internal state while
    # building its per-target-version syntax compatibility map, and a
    # recursive multi-file scan can mutate that state while it is still being
    # enumerated internally - PSScriptAnalyzer itself then throws "Coleção foi
    # modificada; talvez a operação de enumeração não seja executada"
    # (Collection was modified). This is a known upstream fragility, not a
    # bug in this project's source. Analyzing one file per call sidesteps the
    # concurrent-enumeration scenario entirely while preserving full coverage
    # and the same aggregated result shape the rest of this task expects.
    $sourceFiles = Get-ChildItem -Path $SourceRoot -Recurse -Filter '*.ps1' -File
    $results = [System.Collections.Generic.List[object]]::new()

    foreach ($file in $sourceFiles) {
        $fileResults = Invoke-ScriptAnalyzer -Path $file.FullName -Settings $settingsPath
        if ($fileResults) {
            foreach ($r in $fileResults) { $results.Add($r) }
        }
    }

    if ($results.Count -gt 0) {
        $results | Format-Table -AutoSize | Out-String | Write-Build Yellow

        $errors = @($results | Where-Object Severity -eq 'Error')
        if ($errors.Count -gt 0) {
            throw "PSScriptAnalyzer reported $($errors.Count) error-severity finding(s)."
        }
        Write-Build Yellow "Lint completed with warnings (non-blocking)."
    }
    else {
        Write-Build Green "Lint clean: no findings."
    }
}

# ==============================================================================
# TASK: Changelog
# Generates CHANGELOG.md from git history using Conventional Commits parsing.
# ==============================================================================
task Changelog {
    $changelogPath = Join-Path $ProjectRoot 'CHANGELOG.md'

    # Pull commits since the last tag (or all if untagged).
    $lastTag = (& git describe --tags --abbrev=0 2>$null)
    $range   = if ($lastTag) { "$lastTag..HEAD" } else { 'HEAD' }

    $raw = & git log $range --pretty=format:'%s|%h|%an|%ad' --date=short 2>$null
    if (-not $raw) {
        Write-Build Yellow 'No commits found for changelog range.'
        return
    }

    # Conventional Commits classification map.
    $sections = [ordered]@{
        'feat'     = 'Features'
        'fix'      = 'Bug Fixes'
        'perf'     = 'Performance'
        'refactor' = 'Refactoring'
        'docs'     = 'Documentation'
        'test'     = 'Tests'
        'build'    = 'Build System'
        'ci'       = 'Continuous Integration'
        'chore'    = 'Chores'
    }
    $buckets = @{}
    foreach ($k in $sections.Keys) { $buckets[$k] = [System.Collections.Generic.List[string]]::new() }
    $other = [System.Collections.Generic.List[string]]::new()

    $rxConv = [regex]'^(?<type>\w+)(\((?<scope>[^)]+)\))?(?<breaking>!)?:\s*(?<desc>.+)$'

    foreach ($entry in $raw) {
        $parts   = $entry -split '\|', 4
        $subject = $parts[0]
        $hash    = $parts[1]

        $m = $rxConv.Match($subject)
        if ($m.Success) {
            $type  = $m.Groups['type'].Value.ToLowerInvariant()
            $scope = $m.Groups['scope'].Value
            $desc  = $m.Groups['desc'].Value
            # ${scope} (not $scope:) — PowerShell parses "$scope:" inside a
            # double-quoted string as an attempted scope/drive qualifier
            # (e.g. $script:, $global:), which throws at runtime.
            $line  = if ($scope) { "- **${scope}:** $desc ($hash)" } else { "- $desc ($hash)" }
            if ($m.Groups['breaking'].Success) { $line = "- **BREAKING:** $desc ($hash)" }

            if ($buckets.ContainsKey($type)) { $buckets[$type].Add($line) }
            else { $other.Add("- $subject ($hash)") }
        }
        else {
            $other.Add("- $subject ($hash)")
        }
    }

    $sb = [System.Text.StringBuilder]::new()
    [void]$sb.AppendLine('# Changelog')
    [void]$sb.AppendLine()
    [void]$sb.AppendLine("## $(if ($lastTag) { "Unreleased (since $lastTag)" } else { 'Unreleased' }) - $(Get-Date -Format 'yyyy-MM-dd')")
    [void]$sb.AppendLine()

    foreach ($k in $sections.Keys) {
        if ($buckets[$k].Count -gt 0) {
            [void]$sb.AppendLine("### $($sections[$k])")
            [void]$sb.AppendLine()
            $buckets[$k] | ForEach-Object { [void]$sb.AppendLine($_) }
            [void]$sb.AppendLine()
        }
    }
    if ($other.Count -gt 0) {
        [void]$sb.AppendLine('### Other')
        [void]$sb.AppendLine()
        $other | ForEach-Object { [void]$sb.AppendLine($_) }
        [void]$sb.AppendLine()
    }

    Set-Content -Path $changelogPath -Value $sb.ToString() -Encoding UTF8
    Write-Build Green "CHANGELOG.md generated ($($raw.Count) commit(s) processed)."
}

# TASK: Publish
# Builds manifest validation, packages the module, and stages deployment files.
# STRICT dependency: Package (which itself depends on Test -> Lint).
# ==============================================================================
task Publish Package, Changelog, {
    # Validate the manifest is well-formed before any deployment.
    $manifest = Test-ModuleManifest -Path $ManifestPath -ErrorAction Stop
    Write-Build Cyan "Manifest valid: $($manifest.Name) v$($manifest.Version)"

    $deployDir = Join-Path $ArtifactDir 'deploy'
    if (Test-Path $deployDir) { Remove-Item $deployDir -Recurse -Force }
    New-Item -ItemType Directory -Path $deployDir -Force | Out-Null

    # Stage the packaged zip + changelog + legal files for release consumption.
    Copy-Item -Path (Join-Path $ArtifactDir "EscapeFromCorporate-$($manifest.Version).zip") `
        -Destination $deployDir -Force
    foreach ($doc in 'CHANGELOG.md', 'README.md', 'LICENSE', 'NOTICE') {
        $src = Join-Path $ProjectRoot $doc
        if (Test-Path $src) { Copy-Item $src -Destination $deployDir -Force }
    }

    # Emit a deployment metadata descriptor for downstream automation.
    [pscustomobject]@{
        module    = $manifest.Name
        version   = $manifest.Version.ToString()
        stagedUtc = [datetime]::UtcNow.ToString('o')
        artifacts = (Get-ChildItem $deployDir).Name
    } | ConvertTo-Json -Depth 4 |
        Set-Content -Path (Join-Path $deployDir 'deploy-manifest.json') -Encoding UTF8

    Write-Build Green "Publish staging complete: $deployDir"
}

# TASK: Docs
# Generates/updates platyPS markdown from the loaded module CBH and compiles the
# external MAML help (en-US/EscapeFromCorporate-help.xml). Depends on Bootstrap
# so platyPS is vendored locally.
# ==============================================================================
task Docs Bootstrap, {
    Import-Module platyPS -MinimumVersion '0.14.2' -Force

    $helpMarkdownDir = Join-Path $ProjectRoot 'docs\help'
    $helpLocaleDir   = Join-Path $SourceRoot 'en-US'

    if (-not (Test-Path $helpMarkdownDir)) {
        New-Item -ItemType Directory -Path $helpMarkdownDir -Force | Out-Null
    }
    if (-not (Test-Path $helpLocaleDir)) {
        New-Item -ItemType Directory -Path $helpLocaleDir -Force | Out-Null
    }

    # Import the module fresh so platyPS reads current CBH/parameter metadata.
    Import-Module $ManifestPath -Force

    # If markdown does not exist yet, generate it from the module; otherwise sync
    # it so parameter changes are reflected without clobbering hand-edited prose.
    $existing = Get-ChildItem -Path $helpMarkdownDir -Filter '*.md' -ErrorAction SilentlyContinue
    if (-not $existing) {
        Write-Build Cyan 'Generating initial platyPS markdown from module CBH.'
        New-MarkdownHelp -Module 'EscapeFromCorporate' `
            -OutputFolder $helpMarkdownDir `
            -WithModulePage `
            -HelpVersion '1.0.0' `
            -Locale 'en-US' `
            -Force | Out-Null
    }
    else {
        Write-Build Cyan 'Syncing existing markdown with current module metadata.'
        Update-MarkdownHelp -Path $helpMarkdownDir | Out-Null
    }

    # Compile markdown -> MAML external help XML into the module's en-US folder.
    Write-Build Cyan "Compiling MAML into: $helpLocaleDir"
    New-ExternalHelp -Path $helpMarkdownDir `
        -OutputPath $helpLocaleDir `
        -Force | Out-Null

    $maml = Join-Path $helpLocaleDir 'EscapeFromCorporate-help.xml'
    if (-not (Test-Path $maml)) {
        throw "MAML generation failed: $maml was not produced."
    }
    Write-Build Green "External MAML help generated: $maml"
}

> Secure, resumable file dump utility for locked-down corporate Windows environments.
> No admin rights. No third-party tools. Just native PowerShell 5.1 and robocopy.

## The Problem

Corporate laptops are locked down: no Rsync, no Rclone, no module installs, no admin. Yet you need to move tens of gigabytes and hundreds of thousands of files to a home NAS reliably, resumably, and with proof that the copy is exact before deleting anything. `efc` wraps `robocopy.exe` with an asynchronous, non-blocking control layer that turns that gap into a solved problem, without asking for anything the environment won't grant.

## What it does

Everything runs entirely in user space. Dependencies are vendored locally rather than installed globally, and the one operation that sounds like it needs elevation — suspending the robocopy process for pause — uses an ntdll API that works for processes you own without admin rights, degrading gracefully to a soft pause when a corporate EDR agent blocks it.

Transfers are resumable and idempotent: an interrupted job picks up from the exact byte offset in the robocopy log where it left off, so recovering a 30 GB transfer after a dropped VPN connection costs seconds, not a restart from zero. While a transfer runs, you get a live status line — spinner, percentage, throughput, file counters, ETA — and can pause, resume, or abort at any moment with a single keystroke. Before you're told it's safe to delete anything, `efc` runs a differential validation pass against the destination, optionally backed by sampled SHA256 hashing for legal, financial, or otherwise irreplaceable data. And if you just want to know how big a transfer is before committing to it, `-DryRun` projects the file count and total bytes with zero data movement.

## Requirements

`efc` needs only Windows 10 or 11 with Windows PowerShell 5.1 (built in — this is not PowerShell 7) and `robocopy.exe`, which ships with Windows. No administrator rights are required, either to run `efc` or to build and test it; the handful of build/test dependencies (Pester, PSScriptAnalyzer, Invoke-Build, platyPS) are vendored locally into `.\modules\` on first run — see [Building](#building).

# Clone and import (no gallery publish required)

## Usage

```powershell
# Basic transfer to a NAS share
Invoke-EfcJob -Source 'C:\Users\me\Data' -Destination '\\HOME-NAS\Backup\Dump'

# Project the workload first (no copy)
efc -Source 'C:\Data' -Destination '\\NAS\Dump' -DryRun

# Force a clean restart, ignoring prior state
efc -Source 'C:\Data' -Destination '\\NAS\Dump' -Force

# Restartable mode for large files over flaky links
efc -Source 'C:\Data' -Destination '\\NAS\Dump' -Restartable

# Inspect / resume / clean up
Get-EfcJobState
Resume-EfcJob
Clear-EfcState -IncludeLogs
```

At runtime: press **P** to pause, **R** to resume, **A** to abort.

For scenario-by-scenario walkthroughs — sizing a transfer, recovering from a dropped network, sampled-hash validation, troubleshooting, FAQ — see [docs/USAGE.md](docs/USAGE.md). For the full command reference, run `Get-Help Invoke-EfcJob -Full`.

## Architecture

```
Invoke-EfcJob (Public controller)
   |
   +-- Test-EfcPreflight        -> feasibility + DryRun projection (robocopy /L)
   +-- Resolve-EfcResumption    -> idempotent decision (Resume/Force/Conflict)
   +-- Connect-Robocopy         -> background process (no pipe deadlock, /LOG file)
   +-- Watch-RobocopyProcess    -> non-blocking loop:
   |       Read-RobocopyLog       (delta read via FileStream, byte-accurate offset)
   |       Write-EfcSpinner       (in-place UI frame)
   |       Read-EfcKeyCommand     (KeyAvailable poll -> Pause/Resume/Abort)
   |       Suspend-EfcProcess     (ntdll suspend, soft-pause fallback)
   |       Write-EfcState         (throttled atomic checkpoint)
   +-- Test-EfcCopyIntegrity    -> differential validation -> safeToDeleteSource
```

State persists to `%LOCALAPPDATA%\EscapeFromCorporate\state.json` using the **Log Pointer Offset** strategy for exact resumption. The full design rationale — sequence diagrams, the state machine, the failure-mode table — lives in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

#Requires -Version 5.1
<#
.SYNOPSIS
    Reconciles parsed log entries into the running job metrics.

.DESCRIPTION
    Single source of truth for translating parsed robocopy log entries (File/Dir/
    Error) into metric increments. Extracted to eliminate the triplicated switch
    that previously lived in the watch loop's consume, drain, and tail branches.

.PARAMETER State
    The live job state object (mutated in place).

.PARAMETER Entries
    Parsed entries produced by Read-RobocopyLog.

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>
function Add-EfcMetricsFromEntries {
    [CmdletBinding()]
    param(
        [Parameter(Mandatory)] [pscustomobject] $State,
        [Parameter(Mandatory)] [AllowEmptyCollection()] [object[]] $Entries
    )

    Set-StrictMode -Version Latest

    foreach ($entry in $Entries) {
        switch ($entry.Type) {
            'File' {
                $State.metrics.filesCopied++
                $State.metrics.bytesCopied += $entry.Size
            }
            'Dir'   { $State.metrics.dirsCreated++ }
            'Error' { $State.metrics.filesFailed++ }
        }
    }
}

=== src/EscapeFromCorporate/Private/Engine/Connect-Robocopy.ps1 ===
#Requires -Version 5.1
<#
.SYNOPSIS
    Spawns robocopy.exe as a detached background process with file-based logging.

.DESCRIPTION
    Constructs an optimized robocopy argument set for silent, byte-precise logging
    and launches it via [System.Diagnostics.Process]. Deliberately avoids STDOUT
    pipe redirection to prevent buffer deadlocks during multi-gigabyte transfers;
    robocopy writes directly to its own log file (/LOG) which is consumed
    asynchronously by Read-RobocopyLog.

    Returns a descriptor object carrying the live Process handle, PID, resolved
    log path, and the exact command line for state persistence.

.PARAMETER SourcePath
    Absolute source directory to copy from.

.PARAMETER DestinationPath
    Destination directory (local or UNC).

.PARAMETER LogPath
    Full path to the robocopy log file to be written and later polled.

.PARAMETER Restartable
    When set, adds /Z (restartable mode) for resilient resumption of large files.

.PARAMETER RetryCount
    Robocopy /R value. Defaults to 2 to avoid long stalls on locked files.

.PARAMETER RetryWaitSeconds
    Robocopy /W value. Defaults to 5 seconds.

.PARAMETER ProcessFactory
    Injectable script block that produces a started process from a file path and
    argument string. Enables mocking in tests without executing real robocopy.
    Signature: { param($FilePath, $Arguments, $LogPath) -> [pscustomobject] }

.OUTPUTS
    PSCustomObject with: Process, ProcessId, LogPath, CommandLine, Flags, StartedUtc.

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>
function Connect-Robocopy {
    [CmdletBinding()]
    [OutputType([pscustomobject])]
    param(
        [Parameter(Mandatory)]
        [ValidateNotNullOrEmpty()]
        [string] $SourcePath,

        [Parameter(Mandatory)]
        [ValidateNotNullOrEmpty()]
        [string] $DestinationPath,

        [Parameter(Mandatory)]
        [ValidateNotNullOrEmpty()]
        [string] $LogPath,

        [switch] $Restartable,

        [ValidateRange(0, 100)]
        [int] $RetryCount = 2,

        [ValidateRange(0, 3600)]
        [int] $RetryWaitSeconds = 5,

        [scriptblock] $ProcessFactory
    )

    Set-StrictMode -Version Latest

    # --- Ensure the log directory exists (robocopy will not create it) ----------
    $logDir = Split-Path -Parent $LogPath
    if ($logDir -and -not (Test-Path -LiteralPath $logDir)) {
        New-Item -ItemType Directory -Path $logDir -Force | Out-Null
    }

    # --- Build the optimized flag set (see Phase 1 architectural decision #1) ---
    #   /E      : copy subdirectories including empty ones
    #   /BYTES  : sizes in bytes (deterministic parsing, no unit conversion)
    #   /NJH    : no job header
    #   /NJS    : no job summary
    #   /NC     : no file class column (leaner lines)
    #   /NS     : no size column in the per-file listing... 
    #             NOTE: with /BYTES we DO want sizes, so /NS is intentionally omitted here.
    #   /TS     : include timestamps per entry (progress correlation)
    #   /NP     : no per-file percentage spam (we compute our own progress)
    #   /R:n /W:n : bounded retries
    $flags = [System.Collections.Generic.List[string]]::new()
    $flags.Add('/E')
    $flags.Add('/BYTES')
    $flags.Add('/NJH')
    $flags.Add('/NJS')
    $flags.Add('/NC')
    $flags.Add('/TS')
    $flags.Add('/NP')
    $flags.Add("/R:$RetryCount")
    $flags.Add("/W:$RetryWaitSeconds")
    if ($Restartable) { $flags.Add('/Z') }

    # Log routing: /LOG overwrites, /TEE would echo to console (undesired here).
    $flags.Add("/LOG:$LogPath")

    # --- Assemble the argument string with quoted paths -------------------------
    $quotedSource = '"{0}"' -f $SourcePath.TrimEnd('\')
    $quotedDest   = '"{0}"' -f $DestinationPath.TrimEnd('\')
    $argumentLine = '{0} {1} {2}' -f $quotedSource, $quotedDest, ($flags -join ' ')

    $robocopyExe = Join-Path $env:SystemRoot 'System32\robocopy.exe'
    $commandLine = '{0} {1}' -f $robocopyExe, $argumentLine

    Write-Verbose "Robocopy command: $commandLine"

    # --- Launch via injectable factory (real or mocked) -------------------------
    if (-not $ProcessFactory) {
        $ProcessFactory = {
            param($FilePath, $Arguments, $LogPath)

            $psi = [System.Diagnostics.ProcessStartInfo]::new()
            $psi.FileName               = $FilePath
            $psi.Arguments              = $Arguments
            $psi.UseShellExecute        = $false   # required for no-window spawn
            $psi.CreateNoWindow         = $true
            $psi.RedirectStandardOutput = $false   # log goes to file, not pipe
            $psi.RedirectStandardError  = $false
            $psi.WorkingDirectory       = (Split-Path -Parent $FilePath)

            $proc = [System.Diagnostics.Process]::new()
            $proc.StartInfo = $psi
            [void] $proc.Start()

            return [pscustomobject]@{
                Process   = $proc
                ProcessId = $proc.Id
            }
        }
    }

    $spawn = & $ProcessFactory $robocopyExe $argumentLine $LogPath

    if (-not $spawn -or -not $spawn.ProcessId) {
        throw "Process factory failed to return a valid started process descriptor."
    }

    # --- Return the descriptor consumed by the watch loop + state layer ---------
    return [pscustomobject]@{
        Process     = $spawn.Process
        ProcessId   = $spawn.ProcessId
        LogPath     = $LogPath
        CommandLine = $commandLine
        Flags       = $flags.ToArray()
        StartedUtc  = [datetime]::UtcNow.ToString('o')
    }
}

=== src/EscapeFromCorporate/Private/Engine/Suspend-EfcProcess.ps1 ===
#Requires -Version 5.1
<#
.SYNOPSIS
    Suspends or resumes a process using ntdll (no admin required for own processes).

.DESCRIPTION
    robocopy has no native pause. This wrapper P/Invokes NtSuspendProcess /
    NtResumeProcess against a process the current user owns. It resolves and reuses
    the process handle, validates the NTSTATUS return, and gracefully reports failure
    so the caller can fall back to a soft-pause without terminating the transfer.

    Returns $false (never throws) on any failure, since pause is a best-effort UX
    feature and must never crash an in-flight transfer.

.PARAMETER ProcessId
    Target process id (must be owned by the current user).

.PARAMETER Action
    'Suspend' or 'Resume'.

.OUTPUTS
    [bool] indicating whether the native call reported STATUS_SUCCESS.

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>

# Script-scoped flag for ntdll P/Invoke type registration, initialized eagerly
# for the same Set-StrictMode reason documented in ConvertFrom-RobocopyLine.ps1:
# reading an unassigned $script: variable under Set-StrictMode -Version Latest
# throws rather than evaluating as falsy/$null.
$script:EfcNtdllLoaded = $false

function Suspend-EfcProcess {
    [CmdletBinding()]
    [OutputType([bool])]
    param(
        [Parameter(Mandatory)] [int] $ProcessId,
        [Parameter(Mandatory)] [ValidateSet('Suspend', 'Resume')] [string] $Action
    )

    Set-StrictMode -Version Latest

    if (-not $script:EfcNtdllLoaded) {
        $signature = @'
[DllImport("ntdll.dll", SetLastError = true)]
public static extern uint NtSuspendProcess(IntPtr processHandle);
[DllImport("ntdll.dll", SetLastError = true)]
public static extern uint NtResumeProcess(IntPtr processHandle);
'@
        try {
            Add-Type -MemberDefinition $signature -Name 'EfcNtProc' -Namespace 'Efc' -ErrorAction Stop
            $script:EfcNtdllLoaded = $true
        }
        catch {
            Write-Verbose "ntdll P/Invoke unavailable in this environment: $($_.Exception.Message)"
            return $false
        }
    }

    try {
        $proc = Get-Process -Id $ProcessId -ErrorAction Stop

        if ($proc.HasExited) {
            Write-Verbose "Process $ProcessId already exited; suspend/resume is a no-op."
            return $false
        }

        # Materialize the handle once (accessing .Handle forces the OS handle open).
        $handle = $proc.Handle

        $status = if ($Action -eq 'Suspend') {
            [Efc.EfcNtProc]::NtSuspendProcess($handle)
        }
        else {
            [Efc.EfcNtProc]::NtResumeProcess($handle)
        }

        # NTSTATUS: 0 == STATUS_SUCCESS. Anything else is a failure/warning code.
        if ($status -ne 0) {
            Write-Verbose ("Nt{0}Process returned NTSTATUS 0x{1:X8} for PID {2}." -f $Action, $status, $ProcessId)
            return $false
        }

        return $true
    }
    catch {
        Write-Verbose "Suspend/Resume failed for PID $ProcessId ($Action): $($_.Exception.Message). Soft-pause fallback."
        return $false
    }
}

=== src/EscapeFromCorporate/Private/Engine/Watch-RobocopyProcess.ps1 ===
#Requires -Version 5.1
<#
.SYNOPSIS
    Monitors the background robocopy process, rendering live UI and handling control.

.DESCRIPTION
    The heart of the interactive layer. Per iteration it:
      1. Reads only the new log delta (Read-RobocopyLog), never re-reading bytes.
      2. Reconciles metrics (files, bytes, rate, ETA) from parsed entries.
      3. Renders one spinner/progress frame (Write-EfcSpinner).
      4. Polls a single non-blocking keystroke (Read-EfcKeyCommand) and applies
         Pause/Resume/Abort intents.
      5. Persists a throttled checkpoint (Write-EfcState) at the configured interval.
      6. Yields briefly (Start-Sleep) to keep CPU low and the console responsive.

    The loop never performs a blocking WaitForExit; it exits when the process has
    exited AND the trailing log delta has been drained.

.PARAMETER Process
    The started [System.Diagnostics.Process] handle.

.PARAMETER State
    The live job state object.

.PARAMETER StateRoot
    State directory for checkpoint persistence.

.PARAMETER PollIntervalMs
    Loop cadence in milliseconds. Defaults to 200ms.

.OUTPUTS
    The mutated/final state object (with robocopy.exitCode populated).

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>
function Watch-RobocopyProcess {
    [CmdletBinding()]
    [OutputType([pscustomobject])]
    param(
        [Parameter(Mandatory)] $Process,
        [Parameter(Mandatory)] [pscustomobject] $State,
        [Parameter(Mandatory)] [string] $StateRoot,
        [int] $PollIntervalMs = 200
    )

    Set-StrictMode -Version Latest

    $logPath        = $State.robocopy.logPath
    $lastCheckpoint = [datetime]::UtcNow
    $startTime      = [datetime]::UtcNow
    $isPaused       = $false

    Write-Host ''
    Write-Host 'Transfer running. Controls: [P]ause  [R]esume  [A]bort' -ForegroundColor DarkGray
    Write-Host ''

    while ($true) {
        $processExited = $Process.HasExited

        # --- 1. Non-blocking delta read (skip while soft-paused) ---------------
        if (-not $isPaused) {
            $delta = Read-RobocopyLog `
                -LogPath $logPath `
                -ByteOffset $State.logPointer.logByteOffset `
                -PartialLineBuffer $State.logPointer.partialLineBuffer

            $State.logPointer.logByteOffset     = $delta.NewByteOffset
            $State.logPointer.partialLineBuffer = $delta.PartialLineBuffer

            # --- 2. Metrics reconciliation -------------------------------------
            foreach ($entry in $delta.Entries) {
                switch ($entry.Type) {
                    'File'  { $State.metrics.filesCopied++;  $State.metrics.bytesCopied += $entry.Size }
                    'Dir'   { $State.metrics.dirsCreated++ }
                    'Error' { $State.metrics.filesFailed++ }
                }
            }

            $elapsed = ([datetime]::UtcNow - $startTime).TotalSeconds
            $State.metrics.elapsedSeconds = [long]$elapsed

            if ($elapsed -gt 0) {
                $State.metrics.bytesPerSecond = [long]($State.metrics.bytesCopied / $elapsed)
            }
            if ($State.metrics.totalBytesExpected -gt 0) {
                $State.metrics.percentComplete =
                    [double]($State.metrics.bytesCopied / $State.metrics.totalBytesExpected * 100)

                $remaining = $State.metrics.totalBytesExpected - $State.metrics.bytesCopied
                if ($State.metrics.bytesPerSecond -gt 0) {
                    $State.metrics.etaSeconds = [long]($remaining / $State.metrics.bytesPerSecond)
                }
            }
        }

        # --- 3. Render one UI frame -------------------------------------------
        Write-EfcSpinner -State $State -PausedIndicator:$isPaused

        # --- 4. Non-blocking control keystroke --------------------------------
        $command = Read-EfcKeyCommand
        switch ($command) {
            'Pause' {
                if (-not $isPaused) {
                    $suspended = Suspend-EfcProcess -ProcessId $State.robocopy.processId -Action Suspend
                    $isPaused  = $true
                    $State.control.requestedState    = 'Paused'
                    $State.control.pauseRequestedUtc  = [datetime]::UtcNow.ToString('o')
                    $State.status = 'Paused'
                    Write-Host ''
                    Write-Host ('Paused ({0}). Press [R] to resume.' -f
                        ($(if ($suspended) { 'process suspended' } else { 'soft-pause' }))) -ForegroundColor Yellow
                }
            }
            'Resume' {
                if ($isPaused) {
                    [void] (Suspend-EfcProcess -ProcessId $State.robocopy.processId -Action Resume)
                    $isPaused = $false
                    $State.control.requestedState = 'Running'
                    $State.control.resumeCount++
                    $State.status = 'Running'
                    Write-Host ''
                    Write-Host 'Resumed.' -ForegroundColor Green
                }
            }
            'Abort' {
                Write-Host ''
                Write-Host 'Abort requested. Stopping transfer...' -ForegroundColor Red
                $State.control.abortRequested = $true
                if ($isPaused) {
                    [void] (Suspend-EfcProcess -ProcessId $State.robocopy.processId -Action Resume)
                }
                Stop-RobocopyProcess -Process $Process
                $State.status = 'Aborted'
                break
            }
        }

        # --- 5. Throttled checkpoint persistence ------------------------------
        $sinceCheckpoint = ([datetime]::UtcNow - $lastCheckpoint).TotalSeconds
        if ($sinceCheckpoint -ge $State.resumption.checkpointIntervalSeconds) {
            $State.resumption.lastCheckpointUtc = [datetime]::UtcNow.ToString('o')
            Write-EfcState -State $State -StateRoot $StateRoot
            $lastCheckpoint = [datetime]::UtcNow
        }

        # --- 6. Exit condition: process gone -> enter deterministic drain ------
        if ($processExited -and -not $isPaused) {
            # Robocopy may flush trailing bytes AFTER HasExited flips true, because
            # the /LOG buffer is released on teardown. We must drain until the log
            # offset stabilizes across consecutive reads, otherwise the final batch
            # of files would be lost from the metrics.
            #
            # IMPORTANT: the brief sleep runs FIRST, on every iteration including
            # the very first one. A flush can land in the narrow window between
            # HasExited flipping true and our very first drain read; sleeping
            # before that first read (not only between subsequent ones) is what
            # actually gives robocopy the window to finish writing. Checking
            # stability immediately, with no wait at all, would silently drop a
            # flush that hasn't happened yet - which is precisely the race this
            # loop exists to close.
            $drainStable = $false
            $drainGuard  = 0   # hard cap to prevent a pathological infinite drain

            while (-not $drainStable -and $drainGuard -lt 200) {
                # Give robocopy a brief window to flush any remaining buffer
                # BEFORE reading, not just between retries.
                Start-Sleep -Milliseconds 25

                $tail = Read-RobocopyLog `
                    -LogPath $logPath `
                    -ByteOffset $State.logPointer.logByteOffset `
                    -PartialLineBuffer $State.logPointer.partialLineBuffer

                $advanced = ($tail.NewByteOffset -ne $State.logPointer.logByteOffset)

                $State.logPointer.logByteOffset     = $tail.NewByteOffset
                $State.logPointer.partialLineBuffer = $tail.PartialLineBuffer

                if ($tail.Entries.Count -gt 0) {
                    Add-EfcMetricsFromEntries -State $State -Entries $tail.Entries
                }

                if (-not $advanced -and $tail.Entries.Count -eq 0) {
                    $drainStable = $true
                }

                $drainGuard++
            }

            break
        }

        # --- 7. Cooperative yield ---------------------------------------------
        Start-Sleep -Milliseconds $PollIntervalMs
    }

    # --- Finalize --------------------------------------------------------------
    if ($Process.HasExited) {
        $State.robocopy.exitCode = $Process.ExitCode
    }
    $State.history += [pscustomobject]@{
        event = 'ProcessEnded'; timestampUtc = [datetime]::UtcNow.ToString('o')
        detail = "Exit code $($State.robocopy.exitCode); status $($State.status)"
    }
    Write-EfcState -State $State -StateRoot $StateRoot

    Write-Host ''   # move cursor off the status line
    return $State
}

=== src/EscapeFromCorporate/Private/Log/ConvertFrom-RobocopyLine.ps1 ===
#Requires -Version 5.1
<#
.SYNOPSIS
    Parses a single robocopy log line into a structured entry.

.DESCRIPTION
    With flags /BYTES /NC /TS /NP, per-file lines follow a predictable shape:
        <TAB><timestamp><whitespace><size><whitespace><fullpath>
    Directory lines and error lines carry distinct signatures. This parser uses
    a compiled regex to classify each line and extract metrics with minimal
    allocation overhead across hundreds of thousands of lines.

.PARAMETER Line
    A single, complete log line (no trailing newline).

.OUTPUTS
    PSCustomObject with: Type, Size, Path, TimestampRaw  (or $null if unparseable).

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>

# --- Script-scoped regex cache: eagerly initialized at import time ---------
# Set-StrictMode -Version Latest is in effect at the module's defining scope
# (EscapeFromCorporate.psm1). Under that mode, reading a $script: variable
# that has never been assigned throws "A variável '...' não pode ser
# recuperada porque ainda não foi definida" - even inside `if (-not $var)`.
# $null is NOT an acceptable "unset" state; the variable must exist. These
# four lines run once, when this file is dot-sourced into module scope, so
# the lazy-compile check below (`if (-not $script:EfcRxNewFile)`) is safe.
$script:EfcRxNewFile   = $null
$script:EfcRxSizedFile = $null
$script:EfcRxDir       = $null
$script:EfcRxError     = $null

function ConvertFrom-RobocopyLine {
    [CmdletBinding()]
    [OutputType([pscustomobject])]
    param(
        [Parameter(Mandatory)]
        [AllowEmptyString()]
        [string] $Line
    )

    # --- Compiled regexes (module-scoped cache) --------------------------------
    if (-not $script:EfcRxNewFile) {
        $opts = [System.Text.RegularExpressions.RegexOptions]::Compiled -bor
                [System.Text.RegularExpressions.RegexOptions]::CultureInvariant

        # New file: optional leading tabs, action label, size (bytes), path.
        # Path uses a possessive-style bounded match to avoid catastrophic
        # backtracking: consume everything up to trailing whitespace greedily,
        # then trim in code rather than with a lazy quantifier.
        $script:EfcRxNewFile = [regex]::new(
            '^\s*(?<action>New File|Newer|Older|Changed|\*EXTRA File)\s+(?<size>\d{1,19})\s+(?<path>\S.{0,4096})$',
            $opts)

        # Plain per-file line with /NC: "\t   <size>\t<path>" (no action label).
        $script:EfcRxSizedFile = [regex]::new(
            '^\s+(?<size>\d+)\s+(?<path>[A-Za-z]:\\.+|\\\\.+?\\.+)\s*$',
            $opts)

        # Directory marker: "\t   New Dir          N\t<path>" or similar.
        $script:EfcRxDir = [regex]::new(
            '^\s*New Dir\s+(?<count>\d+)?\s*(?<path>.+?)\s*$',
            $opts)

        # Error line: "ERROR n (0x0000000n) ..." 
        $script:EfcRxError = [regex]::new(
            '^\s*ERROR\s+(?<code>\d+)\s+\((?<hex>0x[0-9A-Fa-f]+)\)\s*(?<detail>.+)?$',
            $opts)
    }

    if ([string]::IsNullOrWhiteSpace($Line)) { return $null }

    # --- Defensive length guard against catastrophic regex backtracking --------
    # Real robocopy lines with /BYTES are bounded; a pathologically long line is
    # either corruption or an attack surface. Windows MAX_PATH-era paths plus the
    # action label and size fit comfortably under 4096 chars. Anything longer is
    # rejected as unparseable rather than risking exponential backtracking.
    if ($Line.Length -gt 4096) {
        return $null
    }

    # --- Classification order: cheapest / most frequent first ------------------
    $m = $script:EfcRxNewFile.Match($Line)
    if ($m.Success) {
        return [pscustomobject]@{
            Type         = 'File'
            Action       = $m.Groups['action'].Value
            Size         = [long]$m.Groups['size'].Value
            Path         = $m.Groups['path'].Value.TrimEnd()   # trim in code, not regex
            TimestampRaw = $null
        }
    }

    $m = $script:EfcRxSizedFile.Match($Line)
    if ($m.Success) {
        return [pscustomobject]@{
            Type         = 'File'
            Action       = 'Copy'
            Size         = [long]$m.Groups['size'].Value
            Path         = $m.Groups['path'].Value
            TimestampRaw = $null
        }
    }

    $m = $script:EfcRxDir.Match($Line)
    if ($m.Success) {
        return [pscustomobject]@{
            Type         = 'Dir'
            Action       = 'NewDir'
            Size         = [long]0
            Path         = $m.Groups['path'].Value
            TimestampRaw = $null
        }
    }

    $m = $script:EfcRxError.Match($Line)
    if ($m.Success) {
        return [pscustomobject]@{
            Type         = 'Error'
            Action       = 'Error'
            Size         = [long]0
            Path         = if ($m.Groups['detail'].Success) { $m.Groups['detail'].Value } else { '' }
            TimestampRaw = $m.Groups['code'].Value
        }
    }

    # Unrecognized (banner, blank, separator) -> ignored by caller.
    return $null
}

=== src/EscapeFromCorporate/Private/Log/Read-RobocopyLog.ps1 ===
#Requires -Version 5.1
<#
.SYNOPSIS
    Non-blocking incremental reader for an active robocopy log file.

.DESCRIPTION
    Opens the log via [System.IO.FileStream] with FileShare.ReadWrite so robocopy
    can keep writing while we read. Seeks to the persisted byte offset, reads only
    the new delta, isolates any trailing partial line, parses complete lines into
    structured entries, and returns the advanced byte offset plus residual buffer.

    This function performs a SINGLE poll pass. The watch loop (Phase 4) calls it
    repeatedly. It never blocks waiting for I/O and never re-reads consumed bytes.

.PARAMETER LogPath
    Path to the robocopy log file being polled.

.PARAMETER ByteOffset
    The persisted byte position (from state.logPointer.logByteOffset) to resume from.

.PARAMETER PartialLineBuffer
    Residual text from a previously incomplete line (state.logPointer.partialLineBuffer).

.OUTPUTS
    PSCustomObject with:
      Entries            : parsed structured records (array)
      NewByteOffset      : advanced offset over fully-consumed complete lines
      PartialLineBuffer  : leftover incomplete line to carry into next poll
      RawLinesConsumed   : count of complete lines processed this pass

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>
function Read-RobocopyLog {
    [CmdletBinding()]
    [OutputType([pscustomobject])]
    param(
        [Parameter(Mandatory)]
        [ValidateNotNullOrEmpty()]
        [string] $LogPath,

        [Parameter(Mandatory)]
        [ValidateRange(0, [long]::MaxValue)]
        [long] $ByteOffset,

        [AllowEmptyString()]
        [string] $PartialLineBuffer = ''
    )

    Set-StrictMode -Version Latest

    # Robocopy logs in the console OEM/UTF8 code page; we standardize on UTF8.
    $encoding = [System.Text.Encoding]::UTF8

    $result = [pscustomobject]@{
        Entries           = @()
        NewByteOffset     = $ByteOffset
        PartialLineBuffer = $PartialLineBuffer
        RawLinesConsumed  = 0
    }

    if (-not (Test-Path -LiteralPath $LogPath)) {
        # Log not yet created by robocopy; nothing to consume this pass.
        return $result
    }

    $stream = $null
    try {
        # --- Non-blocking open: coexist with robocopy's write handle -----------
        $stream = [System.IO.FileStream]::new(
            $LogPath,
            [System.IO.FileMode]::Open,
            [System.IO.FileAccess]::Read,
            [System.IO.FileShare]::ReadWrite)

        $currentLength = $stream.Length

        # No growth since last poll -> return unchanged (idempotent).
        if ($currentLength -le $ByteOffset) {
            return $result
        }

        # --- Read ONLY the delta bytes -----------------------------------------
        [void] $stream.Seek($ByteOffset, [System.IO.SeekOrigin]::Begin)

        $deltaCount = [int]($currentLength - $ByteOffset)
        $buffer     = [byte[]]::new($deltaCount)
        $read       = $stream.Read($buffer, 0, $deltaCount)

        $deltaText  = $encoding.GetString($buffer, 0, $read)

        # --- Prepend residual partial line from the previous poll --------------
        $working = $PartialLineBuffer + $deltaText

        # Normalize CRLF -> LF for consistent splitting; keep byte accounting on raw.
        $normalized = $working -replace "`r`n", "`n"
        $segments   = $normalized -split "`n", -1   # -1 keeps trailing empty

        # The final segment is either an incomplete line or empty (if ended on \n).
        $lastIndex     = $segments.Count - 1
        $completeLines = @()
        if ($lastIndex -ge 1) {
            $completeLines = $segments[0..($lastIndex - 1)]
        }
        $newPartial = $segments[$lastIndex]

        # --- Parse complete lines ----------------------------------------------
        $parsed = [System.Collections.Generic.List[object]]::new()
        foreach ($line in $completeLines) {
            if ([string]::IsNullOrWhiteSpace($line)) { continue }
            $entry = ConvertFrom-RobocopyLine -Line $line
            if ($entry) { [void] $parsed.Add($entry) }
        }

        # --- Advance offset by BYTES of fully-consumed content -----------------
        # Authoritative formula: the new offset is the prior offset plus the delta
        # bytes read this pass, minus the bytes still held as the residual partial
        # line (which will be re-read next pass once completed). This stays
        # byte-accurate with multibyte UTF8 because $newPartialBytes is measured
        # via Encoding.GetByteCount, not character length.
        $newPartialBytes = $encoding.GetByteCount($newPartial)

        $result.Entries           = $parsed.ToArray()
        $result.NewByteOffset     = $ByteOffset + ($read - $newPartialBytes)
        $result.PartialLineBuffer = $newPartial
        $result.RawLinesConsumed  = $parsed.Count

        # Sanity clamp: never exceed the file length.
        if ($result.NewByteOffset -gt $currentLength) {
            $result.NewByteOffset = $currentLength
        }

        return $result
    }
    finally {
        if ($stream) { $stream.Dispose() }
    }
}

=== src/EscapeFromCorporate/Private/State/Get-EfcSignature.ps1 ===
#Requires -Version 5.1
<#
.SYNOPSIS
    Computes a deterministic signature for a source/destination path.

.DESCRIPTION
    Normalizes a path (unify separators, lowercase, trim trailing separator)
    and derives a stable SHA1 hash used to build the job's combinedKey for
    idempotent matching. The path need not exist yet (destination may be
    created by robocopy).

.OUTPUTS
    PSCustomObject: Path, NormalizedPath, Hash.

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>
function Get-EfcSignature {
    [CmdletBinding()]
    [OutputType([pscustomobject])]
    param(
        [Parameter(Mandatory)]
        [ValidateNotNullOrEmpty()]
        [string] $Path
    )

    Set-StrictMode -Version Latest

    # Unify forward slashes to backslashes BEFORE trimming/lowering. Without
    # this, 'C:/Data' and 'C:\Data' normalized to different strings ("c:/data"
    # vs "c:\data"), silently weakening both idempotent resume matching and
    # the source/destination self-collision guard in Test-EfcPreflight.
    $normalized = $Path.Trim().Replace('/', '\')
    $normalized = $normalized.TrimEnd('\').ToLowerInvariant()

    $sha1  = [System.Security.Cryptography.SHA1]::Create()
    try {
        $bytes = [System.Text.Encoding]::UTF8.GetBytes($normalized)
        $hash  = ($sha1.ComputeHash($bytes) | ForEach-Object { $_.ToString('x2') }) -join ''
    }
    finally {
        $sha1.Dispose()
    }

    return [pscustomobject]@{
        Path           = $Path.Trim()
        NormalizedPath = $normalized
        Hash           = $hash
    }
}

#Requires -Version 5.1
<#
.SYNOPSIS
    Deserializes the persisted efc job state from LOCALAPPDATA.

.DESCRIPTION
    Reads and validates state.json. Returns $null when no state exists (fresh run).
    Performs schema-version tolerance and guards against corrupt/partial JSON left
    by an abrupt process kill, in which case it attempts the sidecar temp file.

.PARAMETER StateRoot
    Override for the state directory. Defaults to
    $env:LOCALAPPDATA\EscapeFromCorporate. Injectable for testing.

.OUTPUTS
    PSCustomObject representing the state, or $null when absent.

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>
function Get-EfcState {
    [CmdletBinding()]
    [OutputType([pscustomobject])]
    param(
        [string] $StateRoot = (Join-Path $env:LOCALAPPDATA 'EscapeFromCorporate')
    )

    Set-StrictMode -Version Latest

    $statePath = Join-Path $StateRoot 'state.json'
    $tempPath  = "$statePath.tmp"

    if (-not (Test-Path -LiteralPath $statePath)) {
        # A crash mid-rename may have left only the temp file. Try to salvage it.
        if (Test-Path -LiteralPath $tempPath) {
            Write-Verbose "Primary state absent; attempting recovery from temp sidecar."
            $statePath = $tempPath
        }
        else {
            return $null
        }
    }

    try {
        $raw = Get-Content -LiteralPath $statePath -Raw -Encoding UTF8
        if ([string]::IsNullOrWhiteSpace($raw)) { return $null }

        $state = $raw | ConvertFrom-Json -ErrorAction Stop

        if (-not $state.schemaVersion) {
            Write-Warning "State file lacks schemaVersion; treating as invalid."
            return $null
        }

        return $state
    }
    catch {
        Write-Warning "State file is corrupt or unreadable: $($_.Exception.Message)"
        return $null
    }
}

=== src/EscapeFromCorporate/Private/State/Resolve-EfcResumption.ps1 ===
#Requires -Version 5.1
<#
.SYNOPSIS
    Reconciles an existing state.json against the current job request.

.DESCRIPTION
    Compares persisted source/destination signatures with the incoming request and
    determines the correct resumption posture:
      - Resume       : signatures match, job incomplete, not forced -> continue.
      - ForceRestart : -Force supplied -> discard old state, start clean.
      - Conflict     : signatures differ from an active job -> refuse unless -Force.
      - FreshStart   : no prior state -> brand new job.
    Also validates that the resume pointer references an intact line boundary.

.PARAMETER ExistingState
    The deserialized prior state (or $null for a fresh run).

.PARAMETER SourcePath
    The requested source path.

.PARAMETER DestinationPath
    The requested destination path.

.PARAMETER Force
    When set, always resolves to ForceRestart regardless of prior state.

.OUTPUTS
    PSCustomObject: Decision, Reason, ResumeByteOffset, ResumePartialBuffer.

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>
function Resolve-EfcResumption {
    [CmdletBinding()]
    [OutputType([pscustomobject])]
    param(
        [pscustomobject] $ExistingState,
        [Parameter(Mandatory)] [string] $SourcePath,
        [Parameter(Mandatory)] [string] $DestinationPath,
        [switch] $Force
    )

    Set-StrictMode -Version Latest

    $requestSourceSig = Get-EfcSignature -Path $SourcePath
    $requestDestSig   = Get-EfcSignature -Path $DestinationPath
    $requestKey       = '{0}-{1}' -f $requestSourceSig.Hash.Substring(0, 8),
                                       $requestDestSig.Hash.Substring(0, 8)

    $decision      = 'FreshStart'
    $reason        = 'No prior state found; starting a new job.'
    $resumeOffset  = [long]0
    $resumePartial = ''

    if ($Force) {
        return [pscustomobject]@{
            Decision            = 'ForceRestart'
            Reason              = 'Force requested; discarding any prior state.'
            ResumeByteOffset    = [long]0
            ResumePartialBuffer = ''
        }
    }

    if ($null -ne $ExistingState) {
        $existingKey = $ExistingState.signatures.combinedKey

        if ($existingKey -eq $requestKey) {
            # Same job identity. Decide based on completion status.
            if ($ExistingState.status -eq 'Completed') {
                $decision = 'AlreadyCompleted'
                $reason   = 'Matching job already completed; nothing to resume.'
            }
            else {
                # Validate the resume pointer references an intact line boundary.
                $offset  = [long]$ExistingState.logPointer.logByteOffset
                $partial = [string]$ExistingState.logPointer.partialLineBuffer
                $logPath = $ExistingState.robocopy.logPath

                $pointerValid = Test-EfcResumePointer -LogPath $logPath -ByteOffset $offset

                if ($pointerValid) {
                    $decision      = 'Resume'
                    $reason        = "Matching incomplete job found; resuming at byte offset $offset."
                    $resumeOffset  = $offset
                    $resumePartial = $partial
                }
                else {
                    # Pointer drift/corruption: safest is a differential restart.
                    # Robocopy will skip already-copied identical files anyway.
                    $decision      = 'DifferentialRestart'
                    $reason        = 'Resume pointer invalid; restarting with robocopy differential (identical files skipped).'
                    $resumeOffset  = [long]0
                    $resumePartial = ''
                }
            }
        }
        else {
            # A different job occupies the state slot.
            $decision = 'Conflict'
            $reason   = "Existing state targets a different source/destination pair (key '$existingKey' vs '$requestKey'). Use -Force to override."
        }
    }

    return [pscustomobject]@{
        Decision            = $decision
        Reason              = $reason
        ResumeByteOffset    = $resumeOffset
        ResumePartialBuffer = $resumePartial
    }
}

=== src/EscapeFromCorporate/Private/State/Test-EfcResumePointer.ps1 ===
#Requires -Version 5.1
<#
.SYNOPSIS
    Validates that a persisted byte offset lands on an intact log line boundary.

.DESCRIPTION
    A safe resume requires the offset to be <= current log length and to sit exactly
    after a newline (or at EOF). If the log was truncated, rotated, or the offset
    drifted past the file end, the pointer is deemed invalid and the caller falls
    back to a differential restart.

.OUTPUTS
    [bool] indicating whether the pointer is safe to resume from.

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>
function Test-EfcResumePointer {
    [CmdletBinding()]
    [OutputType([bool])]
    param(
        [Parameter(Mandatory)] [string] $LogPath,
        [Parameter(Mandatory)] [long]   $ByteOffset
    )

    Set-StrictMode -Version Latest

    if ($ByteOffset -eq 0) { return $true }               # start-of-file is always valid
    if (-not (Test-Path -LiteralPath $LogPath)) { return $false }

    $stream = $null
    try {
        $stream = [System.IO.FileStream]::new(
            $LogPath,
            [System.IO.FileMode]::Open,
            [System.IO.FileAccess]::Read,
            [System.IO.FileShare]::ReadWrite)

        if ($ByteOffset -gt $stream.Length) { return $false }  # offset past EOF -> drift
        if ($ByteOffset -eq $stream.Length) { return $true }   # exactly at EOF -> valid

        # Inspect the byte immediately preceding the offset: must be a newline (0x0A).
        [void] $stream.Seek($ByteOffset - 1, [System.IO.SeekOrigin]::Begin)
        $prevByte = $stream.ReadByte()

        return ($prevByte -eq 0x0A)   # LF confirms a clean line boundary
    }
    catch {
        return $false
    }
    finally {
        if ($stream) { $stream.Dispose() }
    }
}

=== src/EscapeFromCorporate/Private/State/Write-EfcState.ps1 ===
#Requires -Version 5.1
<#
.SYNOPSIS
    Atomically serializes the efc job state to LOCALAPPDATA.

.DESCRIPTION
    Writes state.json using a temp-then-replace strategy so a mid-write crash never
    leaves a truncated primary file. The updatedUtc stamp is refreshed on every call.
    Uses [System.IO.File]::Replace when a prior file exists (atomic on NTFS), else a
    plain move.

.PARAMETER State
    The state object to persist (PSCustomObject).

.PARAMETER StateRoot
    Override for the state directory. Injectable for testing.

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>
function Write-EfcState {
    [CmdletBinding(SupportsShouldProcess)]
    param(
        [Parameter(Mandatory)]
        [ValidateNotNull()]
        [pscustomobject] $State,

        [string] $StateRoot = (Join-Path $env:LOCALAPPDATA 'EscapeFromCorporate')
    )

    Set-StrictMode -Version Latest

    if (-not (Test-Path -LiteralPath $StateRoot)) {
        New-Item -ItemType Directory -Path $StateRoot -Force | Out-Null
    }

    $statePath   = Join-Path $StateRoot 'state.json'
    $tempPath    = "$statePath.tmp"
    $backupPath  = "$statePath.bak"

    # Refresh the mutation timestamp on every persist.
    $State.updatedUtc = [datetime]::UtcNow.ToString('o')

    if (-not $PSCmdlet.ShouldProcess($statePath, 'Persist efc state')) { return }

    # Serialize to the temp sidecar first.
    $json = $State | ConvertTo-Json -Depth 10
    # UTF8 without BOM keeps byte accounting consistent with the log reader layer.
    $utf8NoBom = [System.Text.UTF8Encoding]::new($false)
    [System.IO.File]::WriteAllText($tempPath, $json, $utf8NoBom)

    if (Test-Path -LiteralPath $statePath) {
        # Atomic swap on NTFS; backup lets Get-EfcState recover on partial failure.
        [System.IO.File]::Replace($tempPath, $statePath, $backupPath)
        if (Test-Path -LiteralPath $backupPath) {
            Remove-Item -LiteralPath $backupPath -Force -ErrorAction SilentlyContinue
        }
    }
    else {
        [System.IO.File]::Move($tempPath, $statePath)
    }
}

=== src/EscapeFromCorporate/Private/UI/Format-EfcBytes.ps1 ===
#Requires -Version 5.1
<#
.SYNOPSIS
    Formats a byte count into a human-readable binary-prefixed string.

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>
function Format-EfcBytes {
    [CmdletBinding()]
    [OutputType([string])]
    param(
        [Parameter(Mandatory)]
        [long] $Bytes
    )

    if ($Bytes -le 0) { return '0 B' }

    $units = 'B', 'KB', 'MB', 'GB', 'TB', 'PB'
    $idx   = [Math]::Floor([Math]::Log($Bytes, 1024))
    $idx   = [Math]::Min($idx, $units.Count - 1)
    $value = $Bytes / [Math]::Pow(1024, $idx)

    return ('{0:N2} {1}' -f $value, $units[$idx])
}

#Requires -Version 5.1
<#
.SYNOPSIS
    Non-blocking capture of a single runtime control keystroke (P/R/A).

.DESCRIPTION
    Polls [Console]::KeyAvailable first and only consumes a key when one is
    actually queued, so the watch loop never blocks waiting for input. Maps
    the P/R/A keys (case-insensitive) to their corresponding control intent;
    any other key, or no key at all, is ignored. On hosts without a real
    console (CI, redirected output, ISE), probing KeyAvailable can throw -
    this function treats that as "no key available" rather than propagating
    the error, matching the same graceful-degradation contract used by
    Test-EfcInteractiveHost.

.OUTPUTS
    [string] one of 'Pause', 'Resume', 'Abort', or $null when no relevant key
    was pressed (or the host has no interactive console).

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>
function Read-EfcKeyCommand {
    [CmdletBinding()]
    [OutputType([string])]
    param()

    Set-StrictMode -Version Latest

    try {
        if (-not [Console]::KeyAvailable) {
            return $null
        }

        # $true suppresses echoing the keypress to the console.
        $key = [Console]::ReadKey($true)

        switch ($key.Key) {
            'P' { return 'Pause' }
            'R' { return 'Resume' }
            'A' { return 'Abort' }
            default { return $null }
        }
    }
    catch {
        # No real console (CI, redirected output, ISE) - treat as no keystroke.
        Write-Verbose "Read-EfcKeyCommand: console probe unavailable ($($_.Exception.Message))."
        return $null
    }

=== src/EscapeFromCorporate/Private/UI/Write-EfcSpinner.ps1 ===
#Requires -Version 5.1
<#
.SYNOPSIS
    Renders a single frame of the efc activity spinner plus live progress metrics.

.DESCRIPTION
    Frame-based spinner intended to be called once per watch-loop iteration. It
    advances a module-scoped frame index and rewrites a single console status line
    in place using cursor positioning, avoiding full-screen redraws. Degrades
    gracefully to periodic linear Write-Host when no interactive raw UI is present
    (e.g. CI, redirected output, ISE).

.PARAMETER State
    The live job state object supplying metrics.

.PARAMETER PausedIndicator
    When set, renders a paused glyph instead of the animated spinner frame.

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>

# Script-scoped spinner state, initialized eagerly at import time. Under
# Set-StrictMode -Version Latest (active at the module's defining scope),
# reading a $script: variable that was never assigned throws "A variável
# '...' não pode ser recuperada porque ainda não foi definida" - even inside
# `if (-not $var)`. This is the same root cause fixed earlier in
# ConvertFrom-RobocopyLine.ps1 ($script:EfcRxNewFile) and
# Suspend-EfcProcess.ps1 ($script:EfcNtdllLoaded); it simply hadn't been
# exercised yet here because the watch loop used to fail upstream first.
$script:EfcSpinnerFrames   = $null
$script:EfcSpinnerIndex    = 0
$script:EfcLastLinearWrite = [datetime]::MinValue

function Write-EfcSpinner {
    [CmdletBinding()]
    param(
        [Parameter(Mandatory)]
        [pscustomobject] $State,

        [switch] $PausedIndicator
    )

    Set-StrictMode -Version Latest

    if (-not $script:EfcSpinnerFrames) {
        # ASCII-only frames for maximum console/codepage compatibility.
        $script:EfcSpinnerFrames = @('|', '/', '-', '\')
        $script:EfcSpinnerIndex  = 0
    }

    $m = $State.metrics

    # Compute a human-readable status segment.
    $pct     = [Math]::Min(100, [Math]::Round($m.percentComplete, 1))
    $etaSpan = [TimeSpan]::FromSeconds([Math]::Max(0, $m.etaSeconds))
    $rate    = Format-EfcBytes -Bytes $m.bytesPerSecond
    $done    = Format-EfcBytes -Bytes $m.bytesCopied
    $total   = Format-EfcBytes -Bytes $m.totalBytesExpected

    if ($PausedIndicator) {
        $glyph = '[||]'
    }
    else {
        $glyph = $script:EfcSpinnerFrames[$script:EfcSpinnerIndex]
        $script:EfcSpinnerIndex =
            ($script:EfcSpinnerIndex + 1) % $script:EfcSpinnerFrames.Count
    }

    $line = ('{0} {1,5}% | {2}/{3} | {4}/s | files {5:N0}/{6:N0} | ETA {7:hh\:mm\:ss}' -f
        $glyph, $pct, $done, $total, $rate,
        $m.filesCopied, $m.totalFilesExpected, $etaSpan)

    # --- Interactive path: rewrite the status line in place --------------------
    if (Test-EfcInteractiveHost) {
        try {
            $raw = $Host.UI.RawUI
            $y   = $raw.CursorPosition.Y
            [Console]::SetCursorPosition(0, $y)
            # Pad to clear any residual characters from a longer previous frame.
            $padded = $line.PadRight([Math]::Max($line.Length, $raw.BufferSize.Width - 1))
            [Console]::Write($padded)
            [Console]::SetCursorPosition(0, $y)
        }
        catch {
            # Cursor ops can fail on odd hosts; fall back silently.
            Write-Host $line
        }
    }
    else {
        # --- Non-interactive: throttle linear output to avoid log spam ---------
        if (([datetime]::UtcNow - $script:EfcLastLinearWrite).TotalSeconds -ge 5) {
            Write-Host $line
            $script:EfcLastLinearWrite = [datetime]::UtcNow
        }
    }
}

=== src/EscapeFromCorporate/Private/Validation/Resolve-EfcEffectiveDestination.ps1 ===
#Requires -Version 5.1
<#
.SYNOPSIS
    Resolves the actual robocopy destination using rsync-style trailing-slash semantics.

.DESCRIPTION
    Mirrors rsync's well-known SRC/DEST convention exactly: a trailing
    separator on Source ('C:\Data\') means "copy the CONTENTS of Source into
    Destination" (robocopy's native /E behavior, unchanged). The ABSENCE of a
    trailing separator ('C:\Data') means "copy Source itself AS A SUBFOLDER of
    Destination" - the effective destination becomes Destination\<leaf name
    of Source>.

    BREAKING CHANGE (v2.0.0): prior versions always used contents-only
    semantics regardless of trailing slash. Any existing script or scheduled
    task calling efc without a trailing separator on -Source will now land
    files one directory level deeper than before.

.PARAMETER Source
    The requested source path, exactly as supplied by the caller.

.PARAMETER Destination
    The requested destination path, exactly as supplied by the caller.

.OUTPUTS
    [string] the effective destination robocopy should actually write to.

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>
function Resolve-EfcEffectiveDestination {
    [CmdletBinding()]
    [OutputType([string])]
    param(
        [Parameter(Mandatory)]
        [ValidateNotNullOrEmpty()]
        [string] $Source,

        [Parameter(Mandatory)]
        [ValidateNotNullOrEmpty()]
        [string] $Destination
    )

    Set-StrictMode -Version Latest

    if ($Source -match '[\\/]$') {
        return $Destination
    }

    # NOTE: deliberately using -replace (regex), NOT .TrimEnd('\', '/').
    # TrimEnd(params char[]) called with two separate string arguments here
    # triggered a PowerShell method-overload/char-array binding failure at
    # runtime ("Cadeia de caracteres deve ter exatamente um caractere de
    # comprimento" / value "" cannot convert to Char), even though neither
    # '\' nor '/' is actually empty. Every other trim in this codebase only
    # ever passed TrimEnd a single character, so this two-argument form was
    # never exercised before. -replace with a regex character class sidesteps
    # .NET overload resolution entirely and is the same technique already
    # used elsewhere in this project (Test-EfcPreflight, ConvertFrom-RobocopyLine).
    $trimmedSource = $Source -replace '[\\/]+$', ''

    # --- Degenerate-root guard: MUST run before any leaf extraction ------------
    # 'C:' (a bare drive letter, no separator) is NOT an empty/opaque string to
    # PowerShell - it is a Windows "drive-relative path", a distinct concept
    # meaning "the current working directory on that drive for this session".
    # Split-Path -Leaf resolves it via the filesystem provider against that
    # live working directory rather than treating it as literal text, so
    # Split-Path -Leaf 'C:' can return something like 'EscapeFromCorporate' if
    # that happens to be the current directory - a completely
    # session-dependent, non-deterministic result. For a tool whose entire
    # purpose is preventing accidental data-destination mistakes, silently
    # nesting under a value that depends on the caller's $PWD at invocation
    # time would be exactly the kind of surprise this guard exists to avoid.
    # A bare UNC root ('\\server' or '\\server\share') is equally leaf-less
    # and is guarded the same way, without ever reaching leaf extraction.
    $isBareDriveRoot = $trimmedSource -match '^[A-Za-z]:$'
    $isBareUncRoot   = $trimmedSource -match '^\\\\[^\\]+(\\[^\\]+)?$'

    if ($isBareDriveRoot -or $isBareUncRoot) {
        return $Destination
    }

    # --- Leaf extraction: pure string/regex, no filesystem-provider cmdlet ---
    # The literal-path form of the path-splitting cmdlet lives in its own
    # exclusive parameter set that declares NONE of the mode switches (leaf,
    # parent, qualifier, etc.). Pairing the literal-path parameter with any
    # mode switch is a terminating ParameterBindingException raised during
    # parameter binding itself, so -ErrorAction SilentlyContinue cannot
    # suppress it - PSScriptAnalyzer cannot flag it either, since both
    # parameters are individually valid on their own. See
    # tests/Unit/SourceHygiene.Tests.ps1, which asserts this combination
    # never appears anywhere under src/.
    #
    # Strip a leading drive-relative prefix ('C:' not followed by a
    # separator, e.g. 'C:Data') first, then split on both separator styles
    # and take the last non-empty segment. This still never consults $PWD.
    $stripped = $trimmedSource -replace '^[A-Za-z]:(?![\\/])', ''
    $segments = @($stripped -split '[\\/]' | Where-Object { $_ -ne '' })

    $leaf = if ($segments.Count -gt 0) { $segments[-1] } else { $null }

    if ([string]::IsNullOrWhiteSpace($leaf)) {
        # Any other unexpected leaf-less shape: fail safe to content-copy
        # semantics rather than guessing.
        return $Destination
    }

    return Join-Path $Destination $leaf
}

=== src/EscapeFromCorporate/Private/Validation/Test-EfcCopyIntegrity.ps1 ===
#Requires -Version 5.1
<#
.SYNOPSIS
    Validates that a completed copy is an exact match between source and destination.

.DESCRIPTION
    Performs a differential verification using 'robocopy /L' (list-only): after a
    successful transfer, a second list pass should report ZERO pending files, since
    every source file must already exist identically at the destination. Any file
    robocopy still lists as needing copy is counted as a mismatch.

    Optionally performs sampled SHA256 hashing of a subset of files for deeper
    assurance on critical transfers, without the cost of hashing every file in a
    tens-of-gigabytes tree.

.PARAMETER SourcePath
    Absolute source directory.

.PARAMETER DestinationPath
    Destination directory (local or UNC).

.PARAMETER SampleHashCount
    Number of files to sample for SHA256 comparison. 0 disables hashing (default).

.PARAMETER RobocopyRunner
    Injectable list-pass runner for testing. Signature: { param($Source,$Dest) -> string[] }

.OUTPUTS
    PSCustomObject: Method, MismatchCount, HashSamplesChecked, HashMismatches.

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>
function Test-EfcCopyIntegrity {
    [CmdletBinding()]
    [OutputType([pscustomobject])]
    param(
        [Parameter(Mandatory)] [string] $SourcePath,
        [Parameter(Mandatory)] [string] $DestinationPath,
        [ValidateRange(0, 10000)] [int] $SampleHashCount = 0,
        [scriptblock] $RobocopyRunner
    )

    Set-StrictMode -Version Latest

    if (-not $RobocopyRunner) {
        $RobocopyRunner = {
            param($Source, $Dest)
            $robo = Join-Path $env:SystemRoot 'System32\robocopy.exe'
            # A post-copy list pass: any listed file == still-pending == mismatch.
            & $robo $Source $Dest /L /E /BYTES /NJH /NJS /NC /TS /R:0 /W:0 2>&1
        }
    }

    $lines        = & $RobocopyRunner $SourcePath $DestinationPath
    $mismatchCount = 0

    foreach ($line in $lines) {
        $entry = ConvertFrom-RobocopyLine -Line ([string]$line)
        if ($entry -and $entry.Type -eq 'File') {
            $mismatchCount++
        }
    }

    # --- Optional sampled hashing ---------------------------------------------
    $samplesChecked = 0
    $hashMismatches = 0
    $method         = 'RobocopyDifferentialList'

    if ($SampleHashCount -gt 0 -and (Test-Path -LiteralPath $SourcePath)) {
        $method = 'RobocopyList+SampledSHA256'

        # Resolve a canonical, separator-normalized base path so the relative-path
        # slice is robust against trailing separators and casing differences
        # between the supplied path and Get-ChildItem's FullName.
        $sourceBase = (Resolve-Path -LiteralPath $SourcePath).ProviderPath.TrimEnd('\')
        $baseLength = $sourceBase.Length

        $allFiles = @(Get-ChildItem -LiteralPath $sourceBase -Recurse -File -ErrorAction SilentlyContinue)
        if ($allFiles.Count -gt 0) {
            $take        = [Math]::Min($SampleHashCount, $allFiles.Count)
            $sourceFiles = $allFiles | Get-Random -Count $take

            foreach ($sf in @($sourceFiles)) {
                # StartsWith guard: skip anything that is not under the base (defensive).
                if (-not $sf.FullName.StartsWith($sourceBase, [System.StringComparison]::OrdinalIgnoreCase)) {
                    continue
                }

                $relative = $sf.FullName.Substring($baseLength).TrimStart('\')
                $destFile = Join-Path $DestinationPath $relative

                $samplesChecked++

                if (-not (Test-Path -LiteralPath $destFile)) {
                    $hashMismatches++
                    continue
                }

                $srcHash = (Get-FileHash -LiteralPath $sf.FullName -Algorithm SHA256).Hash
                $dstHash = (Get-FileHash -LiteralPath $destFile   -Algorithm SHA256).Hash
                if ($srcHash -ne $dstHash) { $hashMismatches++ }
            }
        }
    }

    return [pscustomobject]@{
        Method             = $method
        MismatchCount      = $mismatchCount + $hashMismatches
        HashSamplesChecked = $samplesChecked
        HashMismatches     = $hashMismatches
    }
}

=== src/EscapeFromCorporate/Private/Validation/Test-EfcPreflight.ps1 ===
#Requires -Version 5.1
<#
.SYNOPSIS
    Validates job feasibility and computes baseline file/byte counts.

.DESCRIPTION
    Runs a series of guards - source existence, destination root
    reachability, and source/destination self-collision - and, when
    -Enumerate is set, executes 'robocopy /L /E /BYTES /NJH /NJS /NC /TS' to
    enumerate the pending work WITHOUT copying. The parsed totals seed the
    progress state so the UI can render an accurate ETA from the very first
    frame.

    -Enumerate is requested for EVERY job by Invoke-EfcJob, not only for
    -DryRun requests: without it, a real transfer would never learn its total
    file/byte counts, and percentComplete/ETA would never populate for the
    life of the job. -DryRun (a separate, caller-side concept) only controls
    whether Invoke-EfcJob reports the projection and stops, or proceeds to
    copy after reporting it.

.PARAMETER SourcePath
    Absolute source directory.

.PARAMETER DestinationPath
    The EFFECTIVE destination directory (local or UNC) - i.e. after
    rsync-style trailing-slash resolution has already been applied by the
    caller, not necessarily the raw -Destination argument the user typed.

.PARAMETER Enumerate
    When set, performs the list-only enumeration and returns the projected totals.

.PARAMETER RobocopyRunner
    Injectable script block that executes a robocopy list pass and returns its
    stdout lines. Enables mocking. Signature: { param($Source,$Dest) -> string[] }

.OUTPUTS
    PSCustomObject: IsValid, Messages, TotalFiles, TotalBytes, TotalDirs.

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>
function Test-EfcPreflight {
    [CmdletBinding()]
    [OutputType([pscustomobject])]
    param(
        [Parameter(Mandatory)] [string] $SourcePath,
        [Parameter(Mandatory)] [string] $DestinationPath,
        [switch] $Enumerate,
        [scriptblock] $RobocopyRunner
    )

    Set-StrictMode -Version Latest

    $messages = [System.Collections.Generic.List[string]]::new()
    $isValid  = $true

    # --- Guard 0: reject blank/whitespace-only paths ---------------------------
    if ([string]::IsNullOrWhiteSpace($SourcePath) -or [string]::IsNullOrWhiteSpace($DestinationPath)) {
        $isValid = $false
        $messages.Add("Source and Destination must not be blank or whitespace-only.")
    }

    # --- Guard 1: source must exist and be a directory -------------------------
    if (-not (Test-Path -LiteralPath $SourcePath -PathType Container)) {
        $isValid = $false
        $messages.Add("Source path does not exist or is not a directory: $SourcePath")
    }

    # --- Guard 2: destination root reachability (local drive or UNC share) -----
    # Only the true root needs to exist - robocopy creates arbitrarily deep
    # subdirectories beneath it on its own. Checking just the immediate parent
    # (the old behavior) was both too strict for legitimate brand-new
    # multi-level destinations, and too lax for local drives: an unmounted or
    # disconnected local drive letter was never caught before, only UNC
    # shares were checked at all.
    $destRoot = Get-EfcPathRoot -Path $DestinationPath
    if ($destRoot -and -not (Test-Path -LiteralPath $destRoot)) {
        $isValid = $false
        if ($DestinationPath -like '\\*') {
            $messages.Add("Destination UNC share is unreachable: $destRoot")
        }
        else {
            $messages.Add("Destination drive is not available: $destRoot")
        }
    }

    # --- Guard 3: source/destination self-collision -----------------------------
    # If the destination robocopy will actually write to is the same directory
    # as the source, or lies INSIDE the source tree, robocopy would attempt to
    # copy the source into itself (unbounded growth or a self-referential
    # mirror). DestinationPath here is expected to already be the EFFECTIVE
    # destination (post rsync-nesting resolution), since collisions are often
    # only introduced by that resolution - e.g. `efc C:\Data\Sub C:\Data`
    # resolves, without this guard, to an effective destination identical to
    # the source.
    $sourceSig = Get-EfcSignature -Path $SourcePath
    $destSig   = Get-EfcSignature -Path $DestinationPath

    if ($sourceSig.NormalizedPath -eq $destSig.NormalizedPath) {
        $isValid = $false
        $messages.Add("Source and destination resolve to the same path ('$($sourceSig.NormalizedPath)'). Refusing to proceed.")
    }
    elseif ($destSig.NormalizedPath.StartsWith("$($sourceSig.NormalizedPath)\", [System.StringComparison]::OrdinalIgnoreCase)) {
        $isValid = $false
        $messages.Add("Destination is nested inside source ('$($destSig.NormalizedPath)' is under '$($sourceSig.NormalizedPath)'). This would copy the source into itself. Refusing to proceed.")
    }

    $totalFiles = [long]0
    $totalBytes = [long]0
    $totalDirs  = [long]0

    if ($Enumerate -and $isValid) {
        Write-Verbose "Enumerating pending work via robocopy /L."

        if (-not $RobocopyRunner) {
            $RobocopyRunner = {
                param($Source, $Dest)
                $robo = Join-Path $env:SystemRoot 'System32\robocopy.exe'
                # /L = list only (no copy). Same lean flags as the real transfer.
                & $robo $Source $Dest /L /E /BYTES /NJH /NJS /NC /TS /R:0 /W:0 2>&1
            }
        }

        $lines = & $RobocopyRunner $SourcePath $DestinationPath

        foreach ($line in $lines) {
            $entry = ConvertFrom-RobocopyLine -Line ([string]$line)
            if (-not $entry) { continue }

            switch ($entry.Type) {
                'File' {
                    $totalFiles++
                    $totalBytes += $entry.Size
                }
                'Dir' {
                    $totalDirs++
                }
            }
        }

        $messages.Add("Projection: $totalFiles file(s), $totalBytes byte(s), $totalDirs dir(s).")
    }

    return [pscustomobject]@{
        IsValid    = $isValid
        Messages   = $messages.ToArray()
        TotalFiles = $totalFiles
        TotalBytes = $totalBytes
        TotalDirs  = $totalDirs
    }
}

=== src/EscapeFromCorporate/Public/Invoke-EfcJob.ps1 ===
#Requires -Version 5.1
<#
.SYNOPSIS
    Securely copies a directory tree to a destination (local or UNC) with resumable,
    validated, progress-tracked transfers powered by robocopy.

.DESCRIPTION
    Invoke-EfcJob is the primary controller for Escape From Corporate. It orchestrates
    the full lifecycle of a secure file dump:

      1. Pre-flight validation (existence, root reachability, source/destination
         self-collision) and enumeration of pending work via 'robocopy /L' -
         always performed, so percentComplete/ETA are accurate for every run,
         not only -DryRun requests.
      2. Idempotent resumption reconciliation against any persisted state.json.
      3. Background robocopy spawn with file-based logging (no pipe deadlock).
      4. A non-blocking watch loop rendering a live spinner, ETA, percentage, and
         throughput, while capturing P/R/A keystrokes for Pause/Resume/Abort.
      5. Atomic checkpoint persistence to allow interrupted jobs to resume exactly.
      6. Post-copy integrity validation and a clear "safe to delete" signal.

    Source/Destination use rsync-style trailing-slash semantics: a trailing
    separator on -Source ('C:\Data\') copies the CONTENTS of Source into
    Destination; no trailing separator ('C:\Data') copies Source ITSELF as a
    subfolder of Destination. This matches `rsync SRC DEST` exactly.

    BREAKING CHANGE (v2.0.0): versions prior to 2.0.0 always used
    contents-only semantics regardless of trailing slash. Any existing script
    or scheduled task calling efc without a trailing separator on -Source will
    now land files one directory level deeper than before. Run with -DryRun
    first to confirm the resolved destination before relying on a prior
    automation unattended.

    Because this cmdlet can move or overwrite large amounts of data, it
    carries ConfirmImpact 'High': by default it prompts for confirmation
    before starting a real transfer. Pass -Confirm:$false for unattended or
    scripted use.

    The utility is designed for locked-down corporate Windows 11 environments with no
    administrator privileges and no third-party sync tools; it relies solely on native
    PowerShell 5.1 and robocopy.exe.

.PARAMETER Source
    Path to the source directory to copy from. Positional (rsync-style): the
    -Source flag name itself is optional. A trailing separator ('\' or '/')
    copies Source's CONTENTS into Destination; no trailing separator nests
    Source ITSELF as a subfolder of Destination.

.PARAMETER Destination
    Destination directory. Supports local paths and UNC shares (\\server\share\...).
    Positional (rsync-style): the -Destination flag name itself is optional.

.PARAMETER Force
    Discards any existing job state for this source/destination pair and starts a
    clean transfer. Without -Force, a matching incomplete job is resumed.

.PARAMETER DryRun
    Reports the projected file count, total bytes, and (when Source has no
    trailing separator) the rsync-resolved effective destination, without
    copying anything.

.PARAMETER Restartable
    Enables robocopy restartable mode (/Z) for resilient resumption of large files
    over unreliable network links. Slightly slower but far more robust.

.PARAMETER SampleHashCount
    Number of files to sample for SHA256 content verification during the post-copy
    integrity check. 0 (default) uses robocopy differential list validation only.
    Higher values add content-level assurance at the cost of hashing that many
    random files at both the source and destination.

.PARAMETER StateRoot
    Overrides the state directory. Defaults to $env:LOCALAPPDATA\EscapeFromCorporate.
    Primarily an injection seam for testing.

.PARAMETER Help
    Displays full help for this command and exits without touching any files
    or requiring -Source/-Destination.

.PARAMETER Version
    Displays the installed module version and exits without touching any
    files or requiring -Source/-Destination.

.EXAMPLE
    efc C:\Data\ \\NAS\Dump

    rsync-style, positional: the trailing slash on Source copies its CONTENTS
    directly into \\NAS\Dump (robocopy's native behavior).

.EXAMPLE
    efc C:\Data \\NAS\Dump

    rsync-style, positional: no trailing slash nests Source itself as a
    subfolder, so files land under \\NAS\Dump\Data.

.EXAMPLE
    Invoke-EfcJob -Source 'C:\Data' -Destination 'D:\Backup' -DryRun

    Projects how many files and bytes would be copied, and shows the
    effective (rsync-resolved) destination, without transferring anything.

.EXAMPLE
    Invoke-EfcJob -Source 'C:\Data' -Destination '\\NAS\Dump' -Force

    Ignores any prior state and starts a completely fresh transfer.

.EXAMPLE
    efc -Source 'C:\Data' -Destination '\\NAS\Dump' -Restartable

    Uses the 'efc' alias with restartable mode for large files over a flaky link.

.EXAMPLE
    Invoke-EfcJob -Source 'C:\Legal\Case\' -Destination '\\NAS\Vault' -SampleHashCount 200

    After copying, verifies 200 randomly selected files by SHA256 at both source and
    destination. Any content mismatch fails validation and blocks the safe-to-delete
    signal.

.EXAMPLE
    efc -Help

    Displays full command help and exits.

.EXAMPLE
    efc -Version

    Displays the installed module version and exits.

.INPUTS
    None. Parameters are supplied explicitly.

.OUTPUTS
    PSCustomObject summarizing the final job state (status, metrics, validation,
    safeToDeleteSource) for a normal or resumed run; a projection summary for
    -DryRun; nothing (help text streamed to the console) for -Help; a small
    Name/Version object for -Version.

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0

    At runtime: press P to pause, R to resume, A to abort.

.LINK
    https://github.com/yorgabr/EscapeFromCorporate
#>
function Invoke-EfcJob {
    <#
    .EXTERNALHELP EscapeFromCorporate-help.xml
    #>
    [CmdletBinding(SupportsShouldProcess, ConfirmImpact = 'High', DefaultParameterSetName = 'Run')]
    [Alias('efc', 'Escape-FromCorporate', 'Invoke-Efc')]
    [OutputType([pscustomobject])]
    param(
        [Parameter(ParameterSetName = 'Run', Mandatory, Position = 0)]
        [ValidateNotNullOrEmpty()]
        [string] $Source,

        [Parameter(ParameterSetName = 'Run', Mandatory, Position = 1)]
        [ValidateNotNullOrEmpty()]
        [string] $Destination,

        [switch] $Force,

        [switch] $DryRun,

        [switch] $Restartable,

        # Number of files to sample for SHA256 content verification during the
        # post-copy integrity check. 0 (default) uses robocopy differential list
        # validation only. Higher values add content-level assurance at the cost
        # of hashing that many random files at both source and destination.
        [ValidateRange(0, 10000)]
        [int] $SampleHashCount = 0,

        [string] $StateRoot = (Join-Path $env:LOCALAPPDATA 'EscapeFromCorporate'),

        [Parameter(ParameterSetName = 'Help', Mandatory)]
        [Alias('h')]
        [switch] $Help,

        [Parameter(ParameterSetName = 'Version', Mandatory)]
        [Alias('v')]
        [switch] $Version
    )

    begin {
        Set-StrictMode -Version Latest
        $ErrorActionPreference = 'Stop'
    }

    process {
        if ($PSCmdlet.ParameterSetName -eq 'Help') {
            Get-Help -Name 'Invoke-EfcJob' -Full
            return
        }

        if ($PSCmdlet.ParameterSetName -eq 'Version') {
            $moduleInfo    = $MyInvocation.MyCommand.Module
            $versionString = if ($moduleInfo) { $moduleInfo.Version.ToString() } else { 'unknown' }
            Write-Host "Escape From Corporate (efc) v$versionString"
            return [pscustomobject]@{ Name = 'EscapeFromCorporate'; Version = $versionString }
        }

        # --- rsync-style destination resolution ---------------------------------
        $effectiveDestination = Resolve-EfcEffectiveDestination -Source $Source -Destination $Destination
        if ($effectiveDestination -ne $Destination) {
            Write-Verbose "No trailing separator on Source; rsync-style nesting applies. Effective destination: $effectiveDestination"
        }

        # --- Resolve log path under the state root -----------------------------
        $logDir  = Join-Path $StateRoot 'logs'
        $logPath = Join-Path $logDir ('{0}.log' -f ([guid]::NewGuid().ToString('N').Substring(0, 8)))

        # --- 1. Pre-flight -------------------------------------------------------
        # Enumeration always runs, independent of -DryRun: see the note on
        # Test-EfcPreflight's -Enumerate parameter for why this matters.
        Write-Verbose 'Running pre-flight checks.'
        $preflight = Test-EfcPreflight -SourcePath $Source -DestinationPath $effectiveDestination -Enumerate

        if (-not $preflight.IsValid) {
            foreach ($m in $preflight.Messages) { Write-Error $m }
            throw 'Pre-flight validation failed. See errors above.'
        }

        if ($DryRun) {
            Write-Host ''
            Write-Host 'DryRun projection (no data copied):' -ForegroundColor Cyan
            Write-Host ("  Source                 : {0}" -f $Source)
            Write-Host ("  Destination (as typed) : {0}" -f $Destination)
            if ($effectiveDestination -ne $Destination) {
                Write-Host ("  Destination (effective): {0}" -f $effectiveDestination) -ForegroundColor Yellow
                Write-Host "  (rsync-style: Source has no trailing separator, so it nests as a subfolder)" -ForegroundColor DarkYellow
            }
            Write-Host ("  Files : {0:N0}" -f $preflight.TotalFiles)
            Write-Host ("  Bytes : {0:N0} ({1})" -f $preflight.TotalBytes,
                        (Format-EfcBytes -Bytes $preflight.TotalBytes))
            Write-Host ("  Dirs  : {0:N0}" -f $preflight.TotalDirs)
            return [pscustomobject]@{
                Status                = 'DryRun'
                TotalFiles            = $preflight.TotalFiles
                TotalBytes            = $preflight.TotalBytes
                TotalDirs             = $preflight.TotalDirs
                EffectiveDestination  = $effectiveDestination
            }
        }

        # --- 2. Resumption reconciliation --------------------------------------
        # Uses the RAW Destination (as typed), not the effective one: this keeps
        # job identity (combinedKey) and Resume-EfcJob replay stable and
        # idempotent - the effective destination is re-derived fresh on every
        # run from (Source, raw Destination), rather than persisting an
        # already-nested path that would double-nest on the next resume.
        $existing = Get-EfcState -StateRoot $StateRoot
        $decision = Resolve-EfcResumption -ExistingState $existing `
            -SourcePath $Source -DestinationPath $Destination -Force:$Force

        Write-Verbose "Resumption decision: $($decision.Decision) - $($decision.Reason)"

        switch ($decision.Decision) {
            'Conflict' {
                throw $decision.Reason
            }
            'AlreadyCompleted' {
                Write-Host $decision.Reason -ForegroundColor Green
                return $existing
            }
        }

        # --- 3. Build / rehydrate state ----------------------------------------
        $isResuming = $decision.Decision -eq 'Resume'

        if ($isResuming) {
            $state = $existing
            $state.status = 'Running'
            $state.control.resumeCount++
            $state.logPointer.logByteOffset     = $decision.ResumeByteOffset
            $state.logPointer.partialLineBuffer = $decision.ResumePartialBuffer
            Write-Host "Resuming interrupted job (offset $($decision.ResumeByteOffset))." -ForegroundColor Yellow
        }
        else {
            $state = New-EfcState -SourcePath $Source -DestinationPath $Destination -LogPath $logPath
            $state.status = 'Running'
            $state.metrics.totalFilesExpected = $preflight.TotalFiles
            $state.metrics.totalBytesExpected = $preflight.TotalBytes
            $logPath = $state.robocopy.logPath  # honor state's log path on fresh start

            if ($decision.Decision -eq 'DifferentialRestart') {
                Write-Host 'Note: resuming via robocopy differential. Progress may jump as identical files are skipped.' -ForegroundColor Yellow
            }
        }

        $shouldProcessTarget = if ($effectiveDestination -ne $Destination) {
            "$effectiveDestination (nested under $Destination)"
        }
        else {
            $Destination
        }
        if (-not $PSCmdlet.ShouldProcess($shouldProcessTarget, "Copy from $Source")) {
            return
        }

        # --- 4. Spawn robocopy in background -----------------------------------
        $descriptor = Connect-Robocopy `
            -SourcePath $Source `
            -DestinationPath $effectiveDestination `
            -LogPath $state.robocopy.logPath `
            -Restartable:$Restartable

        $state.robocopy.processId   = $descriptor.ProcessId
        $state.robocopy.commandLine = $descriptor.CommandLine
        $state.robocopy.flags       = $descriptor.Flags
        $state.robocopy.startedUtc  = $descriptor.StartedUtc
        $state.history += [pscustomobject]@{
            event = 'ProcessStarted'; timestampUtc = $descriptor.StartedUtc
            detail = "Robocopy PID $($descriptor.ProcessId)"
        }
        Write-EfcState -State $state -StateRoot $StateRoot

        # --- 5. Watch loop (UI + control + checkpoint) -------------------------
        $final = Watch-RobocopyProcess `
            -Process $descriptor.Process `
            -State $state `
            -StateRoot $StateRoot

        # --- 6. Post-copy validation -------------------------------------------
        if ($final.robocopy.exitCode -lt 8) {
            Write-Verbose "Robocopy exit code indicates success; validating integrity."
            if ($SampleHashCount -gt 0) {
                Write-Verbose "Integrity check will sample $SampleHashCount file(s) for SHA256 verification."
            }

            $validation = Test-EfcCopyIntegrity `
                -SourcePath $Source `
                -DestinationPath $effectiveDestination `
                -SampleHashCount $SampleHashCount

            $final.validation.performed         = $true
            $final.validation.method            = $validation.Method
            $final.validation.mismatchCount     = $validation.MismatchCount
            $final.validation.validatedUtc      = [datetime]::UtcNow.ToString('o')
            $final.validation.safeToDeleteSource = ($validation.MismatchCount -eq 0)
            $final.status = if ($validation.MismatchCount -eq 0) { 'Completed' } else { 'ValidationFailed' }

            # Record traceability of how validation was performed.
            $final.validation | Add-Member -NotePropertyName 'sampleHashCount' `
                -NotePropertyValue $SampleHashCount -Force
            $final.validation | Add-Member -NotePropertyName 'hashSamplesChecked' `
                -NotePropertyValue $validation.HashSamplesChecked -Force
            $final.validation | Add-Member -NotePropertyName 'hashMismatches' `
                -NotePropertyValue $validation.HashMismatches -Force
        }
        else {
            $final.status = 'Failed'
        }

        Write-EfcState -State $final -StateRoot $StateRoot

        # --- 7. Final user notification ----------------------------------------
        Write-EfcSummary -State $final

        return $final
    }
}

=== src/EscapeFromCorporate/Public/Resume-EfcJob.ps1 ===
#Requires -Version 5.1
<#
.SYNOPSIS
    Resumes an interrupted efc job from its persisted state.

.DESCRIPTION
    Convenience wrapper that reads the persisted state and re-invokes Invoke-EfcJob
    using the stored source/destination signatures, continuing from the last
    checkpoint offset. Fails if no resumable state exists.

.PARAMETER StateRoot
    Override for the state directory.

.EXAMPLE
    Resume-EfcJob

    Resumes the most recent interrupted transfer.

.OUTPUTS
    PSCustomObject final job state.

.NOTES
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>
function Resume-EfcJob {
    <#
    .EXTERNALHELP EscapeFromCorporate-help.xml
    #>
    [CmdletBinding()]
    [OutputType([pscustomobject])]
    param(
        [string] $StateRoot = (Join-Path $env:LOCALAPPDATA 'EscapeFromCorporate')
    )

    Set-StrictMode -Version Latest

    $state = Get-EfcState -StateRoot $StateRoot
    if (-not $state) {
        throw 'No persisted job state found; nothing to resume.'
    }
    if ($state.status -eq 'Completed') {
        Write-Host 'Job already completed; nothing to resume.' -ForegroundColor Green
        return $state
    }

    Write-Verbose "Resuming job $($state.jobId) from offset $($state.logPointer.logByteOffset)."
    return Invoke-EfcJob -Source $state.signatures.source.path `
        -Destination $state.signatures.destination.path -StateRoot $StateRoot
}

        }

                            param($L)

                        }
                    } | Should -Not -Throw
                }
            }
        }

        It 'every non-null result has the canonical shape and sane values' {
            $corpus = New-EfcFuzzCorpus -Seed 1337 -Count 500

            foreach ($line in $corpus) {
                $entry = InModuleScope EscapeFromCorporate -Parameters @{ L = $line } {
                    param($L)
                    ConvertFrom-RobocopyLine -Line $L
                }

                if ($null -eq $entry) { continue }

                # Structural contract: all expected members present.
                $entry.PSObject.Properties.Name | Should -Contain 'Type'
                $entry.PSObject.Properties.Name | Should -Contain 'Action'
                $entry.PSObject.Properties.Name | Should -Contain 'Size'
                $entry.PSObject.Properties.Name | Should -Contain 'Path'

                # Type is one of the known classifications.
                $entry.Type | Should -BeIn @('File', 'Dir', 'Error')

                # Size is a non-negative long (never garbage, never negative).
                $entry.Size | Should -BeOfType [long]
                $entry.Size | Should -BeGreaterOrEqual 0
            }
        }

            }
            # Either null, or if matched, Size must have parsed from a real number.
            if ($null -ne $entry -and $entry.Type -eq 'File') {

        }

            $entry = InModuleScope EscapeFromCorporate {

            }
            # The \d+ regex cannot match a leading '-', so this must not be a File

            if ($null -ne $entry) {
                $entry.Size | Should -BeGreaterOrEqual 0
            }
        }
    }

                    param($L)

        }
    }

Describe 'Read-RobocopyLog (incremental delta reader)' {

    BeforeAll {
        Import-Module (Join-Path $PSScriptRoot '..\..\src\EscapeFromCorporate\EscapeFromCorporate.psd1') -Force
    }

    BeforeEach {
        $script:Log = Join-Path $TestDrive ([guid]::NewGuid().ToString() + '.log')
        $script:Utf8NoBom = [System.Text.UTF8Encoding]::new($false)
    }

    It 'reads only new bytes across successive polls' {
        InModuleScope EscapeFromCorporate -Parameters @{ Log = $script:Log; Utf8NoBom = $script:Utf8NoBom } {
            param($Log, $Utf8NoBom)

            # First write: two complete lines.
            $chunk1 = "New File `t1024`tC:\data\a.txt`n" +
                      "New File `t2048`tC:\data\b.txt`n"
            [System.IO.File]::WriteAllText($Log, $chunk1, $Utf8NoBom)

            $pass1 = Read-RobocopyLog -LogPath $Log -ByteOffset 0
            $pass1.Entries.Count       | Should -Be 2
            $pass1.PartialLineBuffer   | Should -BeNullOrEmpty
            $pass1.NewByteOffset       | Should -BeGreaterThan 0

            # Second write: append one more complete line.
            $chunk2 = "New File `t4096`tC:\data\c.txt`n"
            [System.IO.File]::AppendAllText($Log, $chunk2, $Utf8NoBom)

            $pass2 = Read-RobocopyLog -LogPath $Log `
                -ByteOffset $pass1.NewByteOffset `
                -PartialLineBuffer $pass1.PartialLineBuffer

            # Only the newly appended line should be parsed this pass.
            $pass2.Entries.Count | Should -Be 1
            $pass2.Entries[0].Size | Should -Be 4096
        }
    }

    It 'holds an incomplete trailing line in PartialLineBuffer' {
        InModuleScope EscapeFromCorporate -Parameters @{ Log = $script:Log; Utf8NoBom = $script:Utf8NoBom } {
            param($Log, $Utf8NoBom)

            # Write a complete line + a half-written line (no trailing newline).
            $partial = "New File `t512`tC:\data\complete.txt`n" +
                       "New File `t999`tC:\data\incomp"
            [System.IO.File]::WriteAllText($Log, $partial, $Utf8NoBom)

            $r1 = Read-RobocopyLog -LogPath $Log -ByteOffset 0
            $r1.Entries.Count       | Should -Be 1
            $r1.PartialLineBuffer   | Should -Match 'incomp'

            # Complete the previously partial line.
            [System.IO.File]::AppendAllText($Log, "lete.txt`n", $Utf8NoBom)

            $r2 = Read-RobocopyLog -LogPath $Log `
                -ByteOffset $r1.NewByteOffset `

    It 'does not lock the file (robocopy can keep writing)' {

=== tests/Unit/Fuzz.Support.ps1 ===
#Requires -Version 5.1
<#
    Fuzzing support helpers for ConvertFrom-RobocopyLine robustness testing.
    Deterministic (seeded) so CI runs are reproducible. Not a module function;
    dot-sourced by the fuzz test file only.
    Author  : Yorga Babuscan <yorgabr@gmail.com>
    License : Apache License 2.0
#>

function New-EfcFuzzCorpus {
    <#
    .SYNOPSIS
        Produces a deterministic corpus of mutated / adversarial log lines.
    .PARAMETER Seed
        RNG seed for reproducibility.
    .PARAMETER Count
        Number of fuzzed lines to generate (in addition to the fixed adversarial set).
    #>
    [CmdletBinding()]
    [OutputType([string[]])]
    param(
        [int] $Seed  = 1337,
        [int] $Count = 500
    )

    $rng = [System.Random]::new($Seed)

    # --- Building blocks harvested from real robocopy output -------------------
    $actions = @('New File', 'Newer', 'Older', 'Changed', '*EXTRA File',
                 'New Dir', 'ERROR', '', '   ')
    $sizes   = @('0', '1', '1024', '1048576', '9999999999',
                 'NOTANUMBER', '-1', '', '   ', '1.5', '0x400', "$([long]::MaxValue)")
    $paths   = @('C:\data\file.txt',
                 'C:\path with spaces\a b c.dat',
                 'C:\dados\arquivo-ção-üñ.txt',
                 '\\SERVER\share\deep\nested\path.bin',
                 'C:\',
                 '', '   ',
                 'D:\emoji-name.txt',
                 'C:\very' + ('long\' * 60) + 'path.txt')
    $separators = @("`t", "`t`t", "`t   ", "   `t", ' ', '')
    $prefixes   = @('', "`t", "`t  ", '100%', '2024/01/15 09:32:01', '   ', "`t`t")

    # --- Fixed adversarial set (regression-critical edge cases) ----------------
    $fixed = @(
        '',
        ' ',
        "`t",
        "`n",
        "`r`n",
        '------------------------------',
        '   ROBOCOPY     ::     Robust File Copy for Windows',
        '  Total    Copied   Skipped  Mismatch    FAILED    Extras',
        'ERROR 5 (0x00000005) Accessing Source Directory',
        "`tNew File `t`t`t1024`tC:\data\x.txt",
        "New File`t1024`tno-leading-whitespace.txt",
        ("A" * 5000),                          # pathological long line
        "New File `t1024`tC:\ctrl`0char.txt",  # embedded null
        "New File `t $([long]::MaxValue) `tC:\huge.bin"
    )

    $generated = for ($i = 0; $i -lt $Count; $i++) {
        $prefix = $prefixes[$rng.Next($prefixes.Count)]
        $action = $actions[$rng.Next($actions.Count)]
        $sep1   = $separators[$rng.Next($separators.Count)]
        $size   = $sizes[$rng.Next($sizes.Count)]
        $sep2   = $separators[$rng.Next($separators.Count)]
        $path   = $paths[$rng.Next($paths.Count)]

        '{0}{1}{2}{3}{4}{5}' -f $prefix, $action, $sep1, $size, $sep2, $path
    }

    return @($fixed + $generated)
}

        InModuleScope EscapeFromCorporate -Parameters @{ Src = $src; NestedDest = $nestedDest } {
            param($Src, $NestedDest)

            $result = Test-EfcPreflight -SourcePath $Src -DestinationPath $NestedDest
            $result.IsValid | Should -BeFalse
            $result.Messages -join ' ' | Should -Match 'nested inside source'
        }
    }

    It 'rejects when the local destination drive is unavailable' {
        $src = Join-Path $TestDrive 'validsrc'
        New-Item -ItemType Directory -Path $src -Force | Out-Null

        InModuleScope EscapeFromCorporate -Parameters @{ Src = $src } {
            param($Src)

            # Q: is exceedingly unlikely to be mapped on a CI/dev runner.
            $result = Test-EfcPreflight -SourcePath $Src -DestinationPath 'Q:\NoSuchDrive\Dump'
            $result.IsValid | Should -BeFalse
            $result.Messages -join ' ' | Should -Match 'drive is not available'
        }
    }
}

Describe 'Resolve-EfcEffectiveDestination (rsync-style trailing-slash semantics)' {

    BeforeAll {
        Import-Module (Join-Path $PSScriptRoot '..\..\src\EscapeFromCorporate\EscapeFromCorporate.psd1') -Force
    }

    It 'copies contents directly (no nesting) when Source ends with a backslash' {
        InModuleScope EscapeFromCorporate {
            Resolve-EfcEffectiveDestination -Source 'C:\Data\' -Destination '\\NAS\Dump' |
                Should -Be '\\NAS\Dump'
        }
    }

    It 'copies contents directly (no nesting) when Source ends with a forward slash' {
        InModuleScope EscapeFromCorporate {
            Resolve-EfcEffectiveDestination -Source 'C:\Data/' -Destination '\\NAS\Dump' |
                Should -Be '\\NAS\Dump'
        }
    }

    It 'nests Source as a subfolder of Destination when there is no trailing separator' {
        InModuleScope EscapeFromCorporate {
            Resolve-EfcEffectiveDestination -Source 'C:\Data' -Destination '\\NAS\Dump' |
                Should -Be (Join-Path '\\NAS\Dump' 'Data')
        }
    }

    It 'falls back to Destination unchanged for a degenerate drive-root Source' {
        InModuleScope EscapeFromCorporate {
            # Regression guard: 'C:' is a Windows drive-relative path, not an
            # opaque/empty string. A naive Split-Path -Leaf on it resolves
            # against the CURRENT WORKING DIRECTORY on that drive for this
            # PowerShell session - e.g. it can return the project folder's
            # own name - rather than any property of the literal string 'C:'.
            # This must be caught explicitly before Split-Path is ever called.
            Resolve-EfcEffectiveDestination -Source 'C:' -Destination '\\NAS\Dump' |
                Should -Be '\\NAS\Dump'
        }
    }

    It 'falls back to Destination unchanged for a bare UNC server root' {
        InModuleScope EscapeFromCorporate {
            Resolve-EfcEffectiveDestination -Source '\\SERVER' -Destination '\\NAS\Dump' |
                Should -Be '\\NAS\Dump'
        }
    }

    It 'falls back to Destination unchanged for a bare UNC share root' {
        InModuleScope EscapeFromCorporate {
            Resolve-EfcEffectiveDestination -Source '\\SERVER\Share' -Destination '\\NAS\Dump' |
                Should -Be '\\NAS\Dump'
        }
    }
    
    It 'nests the last segment of a deep UNC source' {
        InModuleScope EscapeFromCorporate {
            # Destination is intentionally a UNC path here, not a drive letter
            # (e.g. 'D:\Backup'). Join-Path is provider-aware and resolves the
            # drive through a PSDrive - on any machine/runner without a D:
            # drive attached, Join-Path itself throws DriveNotFoundException,
            # independent of anything Resolve-EfcEffectiveDestination does.
            Resolve-EfcEffectiveDestination -Source '\\SERVER\Share\Projects\Alpha' -Destination '\\NAS\Dump' |
                Should -Be (Join-Path '\\NAS\Dump' 'Alpha')
        }
    }

    It 'nests correctly when Source uses forward separators internally' {
        InModuleScope EscapeFromCorporate {
            Resolve-EfcEffectiveDestination -Source 'C:/Data/Sub' -Destination '\\NAS\Dump' |
                Should -Be (Join-Path '\\NAS\Dump' 'Sub')
        }
    }

    It 'nests a bare relative source name' {
        InModuleScope EscapeFromCorporate {
            Resolve-EfcEffectiveDestination -Source 'Data' -Destination '\\NAS\Dump' |
                Should -Be (Join-Path '\\NAS\Dump' 'Data')
        }
    }

    It 'is deterministic for a drive-relative source (no $PWD dependency)' {
        InModuleScope EscapeFromCorporate {
            # Regression guard: must NOT consult the session's working directory.
            Resolve-EfcEffectiveDestination -Source 'C:Data' -Destination '\\NAS\Dump' |
                Should -Be (Join-Path '\\NAS\Dump' 'Data')
        }
    }

    It 'never throws for adversarial source shapes' -ForEach @(
        'C:', 'C:', 'C:\', '\\S', '\\S\Sh', '\\S\Sh', 'Data', 'C:Data', 'C:\Data\'
    ) {
        InModuleScope EscapeFromCorporate -Parameters @{ S = $_ } {
            param($S)
            { Resolve-EfcEffectiveDestination -Source $S -Destination '\\NAS\Dump' } | Should -Not -Throw
        }
    }
}

Describe 'Watch loop metrics reconciliation' {
    BeforeAll {
        Import-Module (Join-Path $PSScriptRoot '..\..\src\EscapeFromCorporate\EscapeFromCorporate.psd1') -Force
    }

    It 'accumulates files and bytes from a synthetic log and finalizes' {
        InModuleScope EscapeFromCorporate {
            $root = Join-Path $TestDrive ([guid]::NewGuid().ToString())
            New-Item -ItemType Directory -Path $root -Force | Out-Null
            $log  = Join-Path $root 'job.log'

            # Pre-populate a complete synthetic log (process already "exited").
            $content = "New File `t1000`tC:\s\a.txt`n" +
                       "New File `t2000`tC:\s\b.txt`n"
            [System.IO.File]::WriteAllText($log, $content,
                [System.Text.UTF8Encoding]::new($false))

            $state = New-EfcState -SourcePath 'C:\s' -DestinationPath 'C:\d' -LogPath $log
            $state.metrics.totalBytesExpected = 3000
            $state.metrics.totalFilesExpected = 2

            # Fake an already-exited process.
            $fakeProc = [pscustomobject]@{ HasExited = $true; ExitCode = 1 }
            Add-Member -InputObject $fakeProc -MemberType ScriptMethod -Name Kill -Value {}

            # Non-interactive host -> spinner degrades to linear; no cursor ops.
            Mock Test-EfcInteractiveHost { $false }
            Mock Suspend-EfcProcess { $true }

            $final = Watch-RobocopyProcess -Process $fakeProc -State $state `
                -StateRoot $root -PollIntervalMs 10

            $final.metrics.filesCopied | Should -Be 2
            $final.metrics.bytesCopied | Should -Be 3000
            $final.robocopy.exitCode   | Should -Be 1
        }
    }
}
